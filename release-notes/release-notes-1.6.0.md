# TuxunDown 1.6.0

这是一个超级大版：嗅探能探大小了、m3u8 视频流能下了、同一个文件可以多源并下、WiFi 和流量还能双通道一起跑。照例免费、开源、无广告，所有任务都在你的手机本地完成。

## 新功能

- **嗅探探大小**：嗅探结果会逐个探出文件大小（最多前 50 个），可以按大小排序，挑大文件不用再猜；探不到的会老实标「大小未知」，绝不编一个数。
- **HLS / m3u8 下载**：粘贴 m3u8 链接可直接下载视频流，分片并行抓取后按顺序合并成一个 .ts 文件，支持 AES-128 加密的流；断了能续到分片粒度。合并的是原始 TS、未转码，常见播放器都能放。
- **多源并下**：同一个文件有多个镜像地址时可以一起下。开下前会核对各源的总大小一致、并抽查中段内容比对，假源（内容对不上的）会被拒绝并在卡片上写明，不会把错文件拼给你。
- **WiFi + 流量双通道**：设置里可开（默认关），连接轮流走 WiFi 和流量两条路，能开成会在卡片上写明，开不成也会写清原因，不会假装在双通道。
- **统计页**：累计下载量、今日下载量、完成数、平均速度集中看，可一键清除。
- **扫码加链接**：扫二维码直接建下载任务，也能从相册图片里识别；扫到的不是链接会把内容显示出来，不会悄悄丢掉。
- **横屏双列**：宽屏和横屏时任务卡片排成两列，一屏看更多。
- **多任务带宽分配**：全局限速改成总量预算，多个任务一起下时按优先级分（插队的权重更高），不是每个任务各限一份。

## 优化与修复

- 嗅探识别新增 GitHub Releases、SourceForge、archive.org 的下载链接样式，这几类站点的资源更容易被认出来。
- 本版新增的唯一依赖是扫码所需的 zxing 核心库，安装包仍控制在约 2.2 MB。

## 说明

- 本版可直接覆盖安装在 1.2.0 及后续版本之上，不用卸载。
- 双通道会同时消耗 WiFi 和流量，与「仅 WiFi」同时打开时以仅 WiFi 为准；服务器按总量限速时，多源和双通道都提不了速，App 会照常如实提示。
