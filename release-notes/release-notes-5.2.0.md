# TuxunDown v5.2.0

5.2.0 这一版主要让下载状态看得更清楚、找问题更快。主页汇总卡多了一行网络状态：现在用的是什么网络、双通道是不是真的在生效、排队任务被哪个开关挡着，一眼就能看明白。任务标签里还多了一个「异常」筛选，失败的、被各种原因停住的任务点一下就能全找出来。另外，这一版把连接和线程的总量做了一次全面核算，确认多个任务一起下、设置开到极端组合时也稳得住。下面只讲具体改了什么，不承诺速度倍数。

## 看得更清

- **汇总卡新增网络状态行**：主页汇总卡的总速度下面多了一行，写明当前网络是 WiFi、流量还是无网络。没有网络时就直说无网络，不会含糊过去。
- **双通道是不是真生效，一看便知**：开了双通道开关、但系统没给到流量网络时，这一行不会假装在生效；只有 WiFi 和流量两条腿真的都用上了，才会显示「双通道生效中」。
- **排队任务被什么挡着，直接写出来**：排队任务要是被开关挡住，这一行会按顺序只报最先挡住的那个——在等 WiFi、在等充电，还是被流量保护挡着，不用再自己逐个猜。所有任务都暂停着的时候，这一行不显示，免得添乱。

## 找问题更快

- **新增「异常」筛选**：任务标签页多了一个「异常（N）」，只在真有异常任务时才出现。点一下，就会把失败的任务，以及被断网、公共 WiFi 登录页、等充电、等 WiFi 停住的任务一次全筛出来。
- **数字和列表对得上**：标签上的数字就是筛出来任务的个数，两个口径是同一个，不会出现数字写着 3 个、点开只有 2 个的情况。问题都解决后，这个标签会自己消失；在搜索框里搜东西时它也不会出来碍事。

## 稳定性核算

- **连接与线程做了一次全面核算**：这一轮把最极端的情况都算了一遍——同时下载个数开满、全局连接上限拉满，普通下载、流媒体、FTP 几种任务混在一起下。结论是：稳定状态下同时开着的连接总数有硬上限顶着，不会越开越多；任务刚加入时连接数会短暂多一些，那是正在下的分片还没来得及收拢，很快就会回到上限以内，离手机系统能承受的程度还差着好几倍余量。所以这一版没有为此多加限制，也没有改动任何下载逻辑——日常怎么用，还是怎么用。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积：以正式发布包实测为准（仍在 1.5 MB 红线内）。
