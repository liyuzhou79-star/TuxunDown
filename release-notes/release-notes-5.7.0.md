# TuxunDown v5.7.0

5.7.0 这一版专心打磨嗅探：抓得更全（现代网页常用的图片写法和藏在脚本数据里的地址也能找到）、列表更干净（下不了的假链接不再混进来、同一个文件不再重复列几行）、用起来更顺手（嗅探历史可以一键重新嗅探），顺带把测大小的动作放礼貌了。下面只讲具体改了什么。

## 新功能

- **嗅探历史一键重新嗅探**：新建下载框里的嗅探历史，每条记录旁多了「重新嗅探」按钮，点一下就用原来的网页地址重新抓一遍，出来的结果和新嗅探一模一样（包括自动测大小）。抓成功后，这条记录会顶到历史最前面，结果也会成为主页上「上次嗅探结果」的内容；要是这个页面现在打不开了（网站下线、需要登录、断网），原来的历史记录和上次的结果都原样保留，不会因为一次失败就丢掉。
- **嗅探能抓到更多资源了**：现在很多网页用一种叫响应式图片组的写法（同一个位置按屏幕大小准备了好几张图），以前这种写法里的图片抓不到，这一版补上了；写在脚本数据里的媒体地址，如果斜杠被转义过（地址里是 `\/` 这种样子），以前也认不出来，现在同样能找到。

## 修复

- **下不了的假链接不再混进嗅探结果**：有些页面里会混着 file://、content:// 这类地址，看着像文件、其实根本下载不了，以前它们会混进结果列表，要等你点了建任务才发现不行。这一版从抓取源头就拦住：只有真正能下载的链接才进列表；在内置浏览器里通过下载入口碰到这类链接时，也会当场弹一句话说明原因。
- **同一个文件不再重复列几行**：同一个文件被页面用不同写法链接（比如带了 `#` 片段、主机名大小写不同、带了默认端口号），以前会在结果里列成两三行，你勾完建任务时才发现其实是一个。这一版统一了判断口径：列表里只留一行，测大小和建任务去重也用同一套口径对得上。
- **内置浏览器里嗅探到的登录文件能正常建任务了**：以前在内置浏览器里已经登录某个网站，再用嗅探按钮抓到里面的文件建任务，任务不会带上登录状态，下起来就像没登录过一样失败。这一版补上了：和在浏览器里直接点下载一样，建任务时会带上这个网站的登录状态（登录状态只发给原网站，跳转到别的站不会带过去）。

## 优化

- **测大小对网站更礼貌**：嗅探出结果后会自动去测每个文件的大小，以前同一个网站的资源会一拥而上同时测，对方网站如果按地址限流，反而可能连累你接下来真正的下载。这一版改成：同一个网站最多同时测 3 个，不同网站之间照旧并行，总时限不变，测不完的还是标「大小未知」，不会久等。
- **按大小排序的口径复核过了**：这一版专门检查了嗅探结果按大小排序时的老规矩——大小没测出来的资源成组排在所有测出大小的资源后面，每行都明写「大小未知」，不会排到最前面冒充大文件，也不会混在已知大小里冒充最小的文件；页面资源太多只列出一部分时的提示，在排序和筛选之后也照样显示，不会被弄丢。复核结论是现有口径正确，所以排序行为没有改动，只是把这几条规矩补上了自动检查，以后改坏了会当场拦下。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
