# TuxunDown v5.4.0

5.4.0 这一版主要做了三件事：不再重复建任务、镜像的状态看得见了、没能确认的镜像可以由你手动放行。同一个链接不小心粘了两次、或者批量导入时混进了已经在下的链接，以前会多出一个重复任务，现在会直接拦下并说明；多源下载里每个镜像到底确认了没有，以前只能看任务卡片上的一句汇总，现在在镜像管理里逐个写明，你还能对没能确认的镜像自己拿主意。下面只讲具体改了什么，不承诺速度倍数。

## 不再重复建任务

- **同一链接不再重复建**：新建任务时先查重。同一个链接已经在任务列表里、而且还没下完（排队、下载中、暂停、失败都算），就不会再建一个重复任务，会提示你这个链接已经在列表里了。失败的任务也算在内：它还等着你点重试，再建一个只会变成两份记录对着同一个文件。
- **主地址和镜像对上也算同一个**：查重看的是整组地址——新链接和已有任务的主地址对上，或者和它的某个镜像对上，都算同一个文件，不会因为换了个镜像地址就绕过去。
- **批量时会明说跳过了几个**：批量粘贴、导入链接清单或文件、批量嗅探下载时，重复的会被跳过，汇总提示里会写明「跳过了 N 个重复」，不会悄悄吞掉、也不会重复建。
- **已经下完的不拦**：任务已经下载完成的历史记录不算重复。想再下一份、或者换个时间重新下，照样可以正常新建。

## 镜像状态与放行

- **每个镜像的状态都写明**：打开任务的「管理镜像源」，每个镜像下面都会标明它现在的状态：已确认（是同一个文件，会参与下载）、待确认（没能确认是不是同一个文件，可能需要登录，先不用）、已拒绝（已经证明是别的文件）、还没校验（开始下载时会先校验，确认了才用）。
- **状态来自已有的校验记录，不额外联网**：这些状态是下载开始前那次校验顺带记下来的结果，打开这个页面只是把记录显示出来，不会为了显示状态再去联网逐个试探。
- **待确认的镜像可以手动放行**：如果你确定某个待确认的镜像没问题，点「仍然使用这个镜像」就能让它参与这个任务的多源下载。放行时页面会把风险说清楚：万一它其实是别的文件，可能会把文件下坏，下载完成后的哈希校验还会再兜底检查一次。
- **放行只对这个任务有效，随时可取消**：放行是按任务记的决定，不会影响其他任务；在同一个页面点「取消放行」就能收回，下次下载时这个镜像就不会被用了。
- **已拒绝的不能放行**：已经证明是别的文件的镜像没有放行按钮——那不是没确认，而是确认了不是同一个文件，放进来只会把文件下坏。

## 升级路径审计

- 这一版还专门检查了从很老的版本一路覆盖升级上来的情况：老版本存下的设置和各类数据，用现在的版本读会不会被误读、一次性的迁移会不会漏跑或重复跑。逐项核对下来的结论是没有发现会被误读或漏迁移的问题，所以这部分没有改动代码，只是把账查清了。从老版本直接升到这一版可以放心覆盖安装。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积：以正式发布包实测为准（仍在 1.5 MB 红线内）。
