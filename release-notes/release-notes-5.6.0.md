# TuxunDown v5.6.0

5.6.0 这一版主要做瘦身：安装包从约 1.48 MB 降到约 1.38 MB，功能一个没少；同时把上一版还没顾上的几个关键判断补上了自动检查，并给发布流程加了一道体积守门，防止安装包以后不知不觉越做越大。下面只讲具体改了什么。

## 瘦身

- **安装包小了约 100 KB**：5.5.0 的正式包是 1,482,238 字节，这一版按同样的签名口径估算约 1,381,410 字节（最终数字以本页附带的正式包实测为准）。小下来的部分来自下面两处清理，下载功能、界面和设置都没有动。
- **清掉了用不上的多语言库文案**：App 用到的系统组件库自带了一批无障碍文案（标签页、对话框、开关这类控件的读屏文字），被翻译成了几十种语言一起打包进来，占了约 90 KB。TuxunDown 自己的界面是中文的，这些译文绝大多数永远不会被显示出来。这一版只保留默认文案和英文、中文版本，其余语言的库文案不再打包。
- **清掉了一份冗余元数据**：安装包里还带了一组 Kotlin 标准库的元数据文件（约 10 KB），只有反射库在运行时才会去读它，而 TuxunDown 根本没有用到反射库，属于白带的一份重量，这一版一并去掉。
- **语言影响面，说清楚**：App 界面与功能不受影响；使用其他系统语言时，系统组件附带的少数无障碍文案会显示默认英文，而不是该语言的译文。受影响的只是上面说的那批库自带读屏文案，App 自己的界面文字不在其中。

## 稳定性

- **关键判断的自动检查补齐了**：上一版给下载核心做检查时，有几个只影响显示的状态说法排在后面没顾上——校验状态、任务状态、代理类型、内存档位的说法，这一版都补上了自动检查；顺带还补上了内存账本的一个兜底：分片实在抢不到内存额度时有一条强制占用的后路，现在它占多少、还多少也都有检查盯着。这些判断以后要是被改坏，检查会当场拦下。
- **发布流程加了体积守门**：从这一版起，每次打包都会自动量一遍安装包的总大小、打印一份构成明细（代码、资源、图片各占多少），只要超过 1.5 MB（1,572,864 字节）这条红线，整个发布直接失败、包发不出来。5.5.0 时安装包离红线只剩约 90 KB，光靠人盯着日志里的数字不可靠，所以把这道关做成了自动的。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积：本版正式包以发布页附带的文件实测为准（估算约 1.38 MB），并已通过上面说的 1.5 MB 体积守门。
