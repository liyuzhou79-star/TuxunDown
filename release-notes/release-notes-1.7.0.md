# TuxunDown 1.7.0

这一版先做了一轮全仓审计，修掉 4 个确认的毛病，再补上 FTP 下载、下载后哈希校验等一批实用功能。照例免费、开源、无广告，所有任务都在你的手机本地完成。

## 新功能

- **FTP 下载**：支持 ftp:// 链接，断点续传可用，服务器不支持续传时会明确说明。
- **下载后哈希校验**：任务可填期望的 SHA-256 或 MD5，下完自动算一遍比对，卡片上直接显示「对上 / 对不上」；下完之后再补填哈希也会立刻验。
- **孤儿半成品清理**：任务删了但 .part 半成品还留在下载目录里的，可以集中扫出来清掉，不再白占空间。
- **自定义 User-Agent**：内置 6 个常用预置，也可自己填；有些站点对浏览器身份挑剔，换个身份就能下。
- **AMOLED 纯黑**：深色模式可再开纯黑背景，OLED 屏幕更省电、看着也更沉。

## 优化与修复

- **修复 HLS 加密误判**：使用 SAMPLE-AES 等特殊加密方式的流，原先会被当成普通流未解密就合并、还报成功；现在认不出的加密方式会直接说明不支持，不再交给你一个放不了的假文件。
- **修复仅 WiFi 死队列**：开着「仅 WiFi」排队等 WiFi 的任务，原先 WiFi 回来也不会自己开始，现在会自动开下。
- **修复扫码画面撕裂**：扫码预览偶尔会花屏，已修。
- **修复进度假显示**：服务器不给总大小的任务，原先会假显示「已完成 0%」，现在按实际状态显示。
- **存盘更省电**：任务进度落盘改成合并写入（约 1.5 秒最多写一次，关键变化仍立即保存），减少闪存写入和耗电。

## 说明

- 本版可直接覆盖安装在 1.2.0 及后续版本之上，不用卸载。
- 哈希校验只能证明下到的文件和你填的哈希是否一致，哈希本身请从文件发布方提供的页面获取。
