# TuxunDown v5.8.0

5.8.0 这一版围绕「下完之后怎么确认文件没下错」做了一轮修缮：新增了自动读取网站校验文件的开关，手动填校验值时整行粘贴也能认了，还修了几个校验过程中的小毛病；另外，网络抖动时的自动重试学会了自己错峰，不再一拥而上。下面只讲具体改了什么。

## 新功能

- **自动读取校验文件（设置里，默认关）**：很多网站会把一个 .sha256 或 .md5 校验文件放在下载文件旁边，里面写着官方算好的校验值。打开这个开关后，新建下载时会顺手去看一眼旁边有没有这样的文件，有就记下来，文件下完后按网站给的值自动核对，任务卡片上会写明「已按网站给的校验值核对」，对不上也会明说。关着的时候不会发出任何额外请求，一切照旧；这个功能只对普通的 http / https 下载生效，找不到校验文件、或者文件里写了好几个值又对不上文件名时，不会瞎猜，就当没有。

## 优化

- **重试等待自动错峰**：网络或服务器抖动时，以前多个任务、同一个任务的多条连接会在同一瞬间齐刷刷一起重试，反而给对方添堵、也容易一起再失败。这一版给每次重试等待加了随机错峰：大家不再挤在同一时刻，等待时间只会比原来更短、不会更长，原有的等待上限一点没变。

## 修复

- **从发布页整行复制的校验值现在能认了**：以前手动填校验值，只认光秃秃的一串字符；从发布页把整行复制下来——带着文件名、带着「sha256:」这样的前缀、或者另一种常见的写法——都会被拒掉，只能自己动手删。这一版都能认出来了：它只从你粘贴的内容里找出真正的校验值，算法按长度判断、不听标签的；要是粘贴里同时有两个不一样的校验值，它会拒绝并说明，不会随便挑一个。
- **校验进行中改了校验值，旧结果不会错算到新值头上**：以前校验跑到一半时改掉期望值，正在跑的那次结果会落到新值头上，可能把对的说成错的、错的说成对的。现在改了值，那次校验的结果直接作废，界面会说明这次不算数，你按新值重新校验即可。
- **删掉任务会顺手停掉正在跑的校验**：以前删掉一个正在校验的大文件任务，校验还会把整个文件白白读完才停。现在删除会先停校验，不再浪费时间。
- **一处说法改正**：校验对不上时，以前的提示说可以「手动解压」，但应用里其实没有手动解压的入口，容易让人白找。现在提示改成实话：请用文件管理器打开处理。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
