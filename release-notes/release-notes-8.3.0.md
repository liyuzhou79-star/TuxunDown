# TuxunDown v8.3.0

这一版做了三件事：把备份恢复里漏掉的一处设置补齐，让每个站点学到的下载经验能逐站查看和管理，再给任务详情的全程速度曲线加一行小结。都是对着实际使用里的具体问题来的小步改进。

## 新功能

- **下载统计页新增「按主机学习数据」**：以前每个站点学到的经验只能一键全部清除，看不见、也管不了单个站。这一版在下载统计页新增一组，逐站列出域名、学到的最佳连接数、已知的限流上限和上次学习时间；哪个站记错了，可以单独点「忘掉这个站」只清那一个站，原来的全部清除保留。还没有学到数据的站点不显示，没有任何数据时整组不出现。
- **任务详情全程曲线新增一行小结**：全程速度曲线下面现在多一行小结，写明全程峰值、平均速度和采样点数。平均速度按曲线上实际记下来的采样点算，文案里也注明了这个口径；所有数字只来自落盘的采样点，没有推算凑数。

## 修复

- **备份恢复补齐「尾巴双下」开关**：设置里的「尾巴双下」开关此前没有进备份文件，恢复备份时会被漏掉，只能重新打开。这一版已补进备份的保存与恢复，老备份里没有这一项时保持当前设备的设置不变。同时修好了恢复后显示不跟手的问题：恢复备份后，设置页的「尾巴双下」开关、卡片显示项和首页的按站分组三处显示此前不会立即刷新，现在都会立刻按恢复后的设置显示。本轮也把备份恢复整条链复核了一遍：45 个设置项的保存与恢复一一对上，下载统计 8 项对 8 项，任务、设置、统计、按主机学习数据四部分恢复口径一致；老备份缺少某一部分时，不会清掉现有数据。

## 照例

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限，权限仍是原来的 10 项；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
