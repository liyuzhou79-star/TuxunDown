# TuxunDown v2.2.0

2.2.0 专治「最后一公里」和「出事之后」：下载收尾不再被最慢的一条连接拖住；万一闪退，下次打开有解释、有日志、有安全模式；所有报错文案过了一遍，全部翻成人话。

## 新功能

- **收尾加速（endgame 切块）**：大文件下到最后，经常只剩一两块还在慢吞吞地拖，其他连接都闲着。现在一旦所有分片都已开下、还有连接空闲，空闲连接会把「剩余最大的一块」从中切开分着下，切几份按空闲连接数算，最慢的那块不再拖全场。切开的块共用原来的进度记账：整块下完才记完成；如果中途应用被关掉，没下完的块会整块重下（最坏情况是正在下的几块各重下一次，块大小有上限，通常只有几 MB），不会拼出坏文件。
- **崩溃自救**：应用闪退后，下次打开会先出现一个说明页：大概出了什么问题、任务和文件没丢，并提供「复制日志」和「继续打开」两个按钮。日志可以由你自己发给开发者帮助定位问题——它只存在你的手机里，应用不会自动上传任何东西。要是连续闪退 2 次，这次打开会自动进入安全模式：跳过新手引导和剪贴板提示，避免在同一个地方反复崩。

## 优化

- **连接预热复用**：探测、嗅探和正式下载以前每一步都把连接随手断掉，紧接着的请求又要重新握手。现在小响应会把连接好好放回系统的连接池：刚和某个服务器打过交道，马上再下它的文件，第一条连接直接复用热的，少等一次（加密连接尤其明显）。用的是系统自带的连接池，没有自造轮子。
- **省电**：下载引擎原来每 200 毫秒醒来查一次「大家下完没」，现在改成等线程真正结束才被唤醒，长下载里这类无谓唤醒归零。顺带复核了其他等待点（采样节拍、限速、队列待机），它们本来就是按秒级间隔睡的，没有忙等。

## 修复（错误文案审计轮）

- **报错不再露英文和类名**：以前下载失败偶尔会直接把程序内部的英文错误（如连接异常的原文）显示在卡片上，现在统一翻成人话：找不到服务器、连不上、超时、证书问题，各有各的说法和下一步建议。
- **HTTP 数字不再裸奔**：所有「服务器返回 HTTP xxx」都补上了人话解释和可操作建议，比如 403 是可能要登录、404 是文件没了、429 是被限流了、416 点继续会自动整理进度。
- **代理连不上时不再附带英文原文**：改成统一的人话原因。
- **检查更新、嗅探失败、完成改名失败**等入口的报错也一并接入同一套文案，不再各说各话。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 安装包体积：实测 1.25 MB，和上一版基本持平，新功能没有让包变臃肿。
