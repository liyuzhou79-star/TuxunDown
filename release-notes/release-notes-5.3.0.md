# TuxunDown v5.3.0

5.3.0 这一版主要做了三件事：开局更稳、几处说法对齐、处理失败更快。多个任务一起开始下载时，连接数的爬升变平滑了，不再短暂冲过你设的全局上限；任务卡片、通知、桌面小部件和快捷磁贴这几个地方的状态说法做了一次逐项对账，之前对不上的几处都改成同一个口径；失败任务攒多了也不用一个个点，「异常」页顶部多了批量处理入口。下面只讲具体改了什么，不承诺速度倍数。

## 开局更稳

- **连接数平滑爬升**：以前多个任务同时开始、或下载中途又有新任务加入时，连接总数会短暂冲到全局上限的约 1.8 倍，过一会儿才收回来。这一版给连接数的增长加了平滑斜率：爬升一步步来，不再短暂冲过上限，对服务器也更友好。
- **该快的照旧快**：稳态速度和每个任务的目标连接数都没变，新任务开局的 16 条爆发也原样保留；你把全局上限调低时仍然立即生效，不会被平滑拖慢。

## 四处说法对齐

- **百分比算法统一**：单个任务的完成百分比，卡片和通知现在用同一套算法算，不会再出现同一个任务两处数字不一样。
- **失败就叫失败**：磁贴和汇总卡以前会把失败任务混进「已暂停」里说，现在单独叫「失败」，和「已暂停」分开写，一眼能分清哪些是停了、哪些是出错了。
- **全在排队时不再误报**：桌面小部件以前只要队列里有未完成的任务就写「正在下载」，哪怕全都在排队或停泊着。现在全在排队时会如实写「排队中」，真有任务在下才写「正在下载」。
- **连接数显示实时条数**：任务卡片上原来一边写「想要 N 条」、另一行又拿目标数当成实际连接数，两行会对不上。现在卡片显示的是实时在跑的条数，和「想要 N 条、现在 M 条」那行不再打架。
- **等登录不再误报成等网络**：连上需要登录的公共 WiFi、任务停泊等待时，通知以前会写成等待网络恢复。现在会如实说「等待 WiFi 登录」，登录完成后自动继续。
- **大小未知不再假装估算**：文件大小未知的任务，以前剩余时间会一直显示「计算中…」，其实永远算不出来。现在会明说还不知道大小、没法估算，不再假装。

## 处理失败更快

- **失败任务批量处理**：失败任务有 2 个以上时，「异常」标签顶部会出现「失败任务批量处理」入口，点一下就能打开换招重试，统一给这些失败任务换浏览器标识（UA）或改成单线程再排队，不用再一个个点开处理。
- **停泊中的不算在内**：停泊中的任务是在等网络、登录或充电等条件恢复，条件到了会自动继续，不需要重试，所以不纳入这个批量入口，入口旁边的说明里也写明了这一点。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积：以正式发布包实测为准（仍在 1.5 MB 红线内）。
