# TuxunDown v7.2.0

这一版没有新功能，专做一件事：把敏感信息的出口再收紧一轮。下载器每天经手的正是链接、登录状态和密码这类东西——备份文件会带走、诊断信息会复制出去、任务清单会分享给别人。这一版逐个检查了这些出口，该拦的拦住、该提醒的提醒，让你把东西发出去之前心里有数。

## 安全补强

- **备份导入加了一道链接门**：导入备份时，主链接和镜像地址只接受 http、https、ftp 开头的。备份文件如果被人动过手脚、混进了指向本机文件的链接，导入时会被直接跳过，不会照单全收建出奇怪的任务。
- **自定义密钥请求头不进备份**：以前导出备份只剔除 Cookie 和授权头，现在名字里带密钥、令牌、密码这类字样的自定义请求头（比如 X-Api-Key、X-Auth-Token）也会一并剔除，不会跟着备份文件到处走。本机专属的下载目标位置同样不再写进备份。
- **备份文件本身照实说明**：下载链接为了导入后能继续用，在备份里是原样保留的。所以备份文件不要随手转发给别人，这一点诊断页的「安全现状」里也会写明。

## 复制与分享脱敏

- **统一了一把脱敏尺**：任务诊断、一键体检、崩溃日志和下载报告，以前各用各的遮盖规则，难免有漏。现在全部改走同一套处理：链接去掉参数和账号信息，密钥、令牌、密码类内容和整行 Cookie 都会被遮掉，复制出去报障也不怕顺手把敏感内容带出去。
- **任务的错误说明也过脱敏**：诊断信息里带的失败原因同样先遮再复制，哪怕这条说明是从导入的备份里来的也一样。
- **分享清单多了凭据提醒**：把一队任务分享成链接清单时，如果某个链接里带着参数或账号信息，清单末尾会多加一行提醒。清单格式没有变，对方照样能整段粘回重建任务，只是发之前先提醒你确认一下。

## 诊断页「安全现状」

- 诊断页新增一栏「安全现状」，打开就能看到：这个应用一共申请了哪些权限、有多少个组件对外开放、代理密码目前是未设置还是已经用系统钥匙串加密保存（AES-256/GCM）。
- 这里只说保存方式，密码本身不会显示出来，也不会写进任何复制出去的内容。如果是很早以前用旧方式原样保存的密码，这里也会照实写原样保存，不会假装成已加密。

## 嗅探浏览器

- **可以清除登录状态了**：用内置浏览器嗅探时，有些网站需要先登录才能点到下载，登录状态以前会一直留在浏览器里，没有地方能退。现在嗅探浏览器里多了一个「清除浏览器登录状态」按钮，点一下就清掉全部网站的登录状态和浏览数据，用完即走更放心。
- 顺带把浏览器的混合内容设置写成了明确禁止，行为和以前一致，只是从「靠系统默认」变成「写死在设置里」，以后系统默认变了也不会受影响。

## 照例

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限，权限仍是原来的 10 项；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
