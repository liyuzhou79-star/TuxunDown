# TuxunDown v5.9.0

5.9.0 这一版主要让「连接到底分给了谁、被什么卡住」变得看得见：任务详情里多了一行连接预算，连接开不满的时候不用再猜；顺手修了一个测速的老毛病——配了代理时测速以前不走代理，数字一直对不上实际下载。下面只讲具体改了什么。

## 新功能

- **任务详情新增「连接预算」行**：正在下载的任务，详情里现在会写明它当前分到了多少条连接，以及这个数字是被什么压住的——是所有任务合计的全局连接上限、是这个站点以前限流过留下的上限、还是单个任务自己的连接上限。数字跟着实时刷新：别的任务结束、腾出连接，这个任务分到的数量变了，这一行马上就能看出来；实际正在跑的连接数还在爬升、暂时没跟上分到的数量时，也会如实标出来。排队、暂停或已完成的任务不会显示这一行，不拿假数字糊弄人。

## 修复

- **测速现在走代理设置了**：以前配了代理时，内置测速和连接数对比实测会绕过代理直接连，测的是直连的速度，跟实际下载走的路不是一条，结果自然对不上；有些只能通过代理访问的地址还会直接测出 0。现在测速和下载走同一套代理设置，测出来的数字才作数。
- **测速页补上抢带宽提醒**：测速不会暂停正在下载的任务，两边会共用同一份带宽互相抢，所以有任务在下时测出来的数字会偏低。以前连接数对比实测有这个提醒、测速页没有，容易让人误以为是网络变慢了；现在测速开始时会记下当时有几个任务在下，测速中和结果里都会把这句话说明白。

## 说明

- **全局限速的分配口径**：开了全局限速后，总带宽按任务优先级切分，每个正在下载的任务都有一份保底份额，任何一个任务都不会被其他任务饿着。代价是：某个任务暂时用不完自己那份时，多出来的份额不会转借给别的任务，要等它结束或暂停后才重新分配——这是有意保留的公平取舍，不是卡住了。重新分配的速度也已经核实：带宽份额在任务状态变化后的下一次写入就生效；连接数最快几秒内跟上，边角情况下最多约十秒，不需要重启任务。
- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
