# TuxunDown 1.3.0

这一版做了一次全仓审计，把十几个藏着的毛病一次修掉，同时继续提速、补上新手引导和一批顺手的小功能。照例免费、开源、无广告，所有任务都在你的手机本地完成。

## 新功能

- **新手引导**：每个新版本第一次打开都会弹出 5 页全屏引导，讲清这一版更新了什么、核心用法和提速小贴士；设置里随时可以重新查看。以后每次升级都会触发一次，不会再对新功能一头雾水。
- **剪贴板一键建任务**：复制过链接再打开 App，会直接问你要不要建下载任务，同一个链接不会反复打扰。
- **批量粘贴**：新建任务时一次粘贴多行链接，会逐条处理——直链直接建任务，网页自动去嗅探。
- **全局限速**：设置里可选不限 / 512 KB / 1 MB / 3 MB / 5 MB，下载途中改了立即生效。
- **任务搜索与排序**：任务多了可以按名字或链接搜索，按默认 / 大小 / 时间排序。
- **完成提醒**：下完可震动（默认开）和播放提示音（默认关），在设置里切换。

## 优化与修复

- **同名文件绝不误删**：以前完成改名时可能把下载目录里你自己的同名文件删掉，现在自动起名为「名字 (1)」这类新名字，永远不碰别人的文件。
- **任务数据更稳**：任务列表改成原子保存并带一份备份，写入中途断电也不会把全部任务记录弄丢。
- **续传更可靠**：分片失败重试从已写到的位置接着下，不再整片重下；续传前会核对服务器上的文件有没有变过，变了会重置并写明原因，不会把新旧文件拼在一起。
- **提速一轮**：分块更细（大文件分成更多小块，空闲连接抢尾巴更灵活）、卡住不动的连接 12 秒就淘汰换新的、找最佳连接数的试探更快、读写缓冲加大。
- **仅 WiFi 更严**：下载途中 WiFi 断了会立刻暂停并写明，不会偷偷改用流量。
- **失败重试保留进度**：点重试接着已下的部分继续，不用从头来；存储空间不足会直接说清，不再报一串看不懂的错误。
- **图标微调**：启动图标字形再缩小一圈，视觉更清爽。
- 修复了 1.3.0 首个验收包在安卓 8 以上机型打开闪退的问题（已在同一版本号内修复重发，本页提供的就是修复后的包）。

## 说明

- 本版可直接覆盖安装在 1.2.0 之上，不用卸载。
- 服务器如果按 IP 总量限速，多开连接也提不了速，App 会照常如实提示，不会假装在加速。
