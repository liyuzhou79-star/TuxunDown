# TuxunDown v4.3.0

4.3.0 做四件事：让上一版的「连接数对比实测」测完能直接用上、给 m3u8 流媒体下载提速、修掉几个存储和文件边界上的真问题、给嗅探大页面加上护栏。没有承诺任何速度倍数，下面只讲具体改了什么。

## 新功能

- **对比实测结果可一键应用到站点**：诊断页的「连接数对比实测」测出某个链接用多少条连接最快之后，结果下方多了一个应用按钮。点下去先弹确认，说清三件事：这个结果只对测的那个域名生效；应用之后仍然受全局连接上限和这台服务器记住的限流上限管着，不会硬冲；随时可以回退。确认后，这个站点以后的下载就按实测出的连接数起步，省掉每次重新试探。
- **设置里可清除按主机学习数据**：统计相关的设置区新增「清除按主机学习数据」按钮。App 平时记住的每个站点的最佳连接数、限流上限（包括上面手动应用的结果）可以一键清掉，回到默认的试探方式。觉得某个站点的下载行为不对劲时，这是最直接的重置办法。

## 优化

- **HLS 流媒体下载并发自适应**：以前 m3u8（HLS）下载固定只开 4 条连接同时取分段。现在并发数会跟着走：起步按这个站点记住的最佳连接数来（没记过的用一个适中的默认值），下载过程中写数据的速度跟不上取分段的速度就加开连接，出现重试就收回来，全局连接上限压着的时候也不会越界。效果是分段取回更快、合并等待更短，整体下起来更快也更稳。原有的保障都没动：分段逐个重试、AES-128 解密、断点续传（按已下好的分段接着下）、不支持的加密方式照样明说拒绝。
- **嗅探测大小不再久等**：嗅探列出资源后逐个测文件大小，以前资源多时最坏要等很久。现在测大小有了总时限，到点还没测到的就标大小未知，不再让你一直停在「正在测大小」。

## 修复

- **改名撞满不再卡住**：保存文件时如果同名文件已经堆了非常多（比如同一个名字后面排了几百个编号），以前找一个不重名的名字会一个一个查下去、卡在完成这一步。现在编号找满后改用时间后缀生成新名字，还是不行就明确报错，绝不会覆盖掉别人的文件。
- **文件在下载途中被删，不再假报完成**：下载过程中如果你在文件管理器里把正在下的那个文件删了，以前任务收尾时照样报「下载完成」，还留着一个指向已删文件的记录，点开是空的。现在收尾时会确认文件还在，不在了就如实标失败并写明原因，请你重新下载。
- **SD 卡出问题时原因说对了**：下载写到一半存储设备出问题（比如 SD 卡被拔出或损坏），以前报错统一说成「网络或读写出错」，让你白白去查路由器。现在能分清这是存储设备的问题，提示里会明说先检查存储设备。
- **自定义文件夹授权失效不再白重试**：用自定义下载文件夹时，如果系统把文件夹授权收回了，以前开了自动重试的任务会白白重试好几轮，最后的提示还埋着真正原因。现在这类问题会直接停下、标失败，失败卡片上写明出路：去设置里重新选一次下载文件夹。
- **孤儿清理不再误删刚开始的下载**：清理没人认领的半成品文件时，刚创建不到一分钟的文件一律跳过——新任务的文件是先建好再登记的，这一下避免了在登记完成前的空当里把正在下的文件当孤儿删掉。
- **嗅探大页面不再卡**：资源特别多的大页面，以前解析会把整个页面从头扫到尾，页面越怪扫得越久。现在解析有了数量和时间上限，超了就停下，把已经找到的资源照常列出来，并在列表上方明说「这个页面资源太多，只列出了一部分」，不会让你对着一个卡住的解析干等。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。本版的应用结果、并发调整、存储判断和嗅探护栏都是纯逻辑，带单元测试。
- 安装包体积：以正式发布包实测为准（仍在 1.5 MB 红线内）。
