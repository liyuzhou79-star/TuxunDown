# TuxunDown v3.1.0

3.1.0 做三件新东西和一轮审计：已下载文件页能「找重复文件」了；任务优先级从「插队 / 普通」扩成高 / 中 / 低三档，排队顺序和限速份额都按档走；嗅探结果的筛选条件会被记住，批量下载前先把账算给你看。第 17 轮审计核的是设置与备份完整性——全部设置逐项过「有入口、真生效、进备份、恢复后真应用」，任务字段逐项过备份往返。

## 新功能

- **找重复文件**（已下载文件页）：点「找重复文件」后分两步走——先按文件大小分组（免费、瞬间完成），只有大小完全相同的文件才有可能是重复的；再把这批候选逐个流式算 SHA-256 比对内容，大小和内容都一样才算一组重复。校验在后台进行、有进度、随时能取消，只读不删。结果按组列出：每份多大、共几份、只留一份能回收多少。删哪些由你逐个勾选，点「删除所选」后还有一次确认，确认框会写清共删几个、回收多少；**某一组的所有副本都被勾选时会有专门警告**——删完那组文件就一份不剩了。有任务记录的文件删除时连记录一起清（和本页单删的规则一致），删完列表自动刷新。
- **任务优先级三档**（任务详情）：高 / 中 / 低，排队和限速都认它。排队时：到期可下的任务里高优先级先开始，同档内仍按排队先后（预约时间没到的高优先级不会挡住已到期的普通任务）。限速时：多个任务同时下载，全局限速的总量按 高：中：低 = 2 : 1 : 0.5 分配。**老数据自动映射**：优先级就存在原来的字段里——以前点过「插队」的任务存的值正好就是「高」，升级后直接就是高优先级，不用重设；「插队」按钮保留，点了仍然是移到队首并升到高档。
- **嗅探筛选记忆 + 批量估算**：嗅探结果对话框里选的类型和新加的「最小大小」（不限 / ≥1MB / ≥10MB / ≥100MB）会被记住，下次嗅探打开时自动带上（记住的类型这次页面里没有时自动回「全部」，不会把列表筛空）。最小大小只拦测出大小的资源：大小还没测出来或测不到的照常显示——列表里有标注。勾选资源后，对话框下方直接给出账：已选几个、已知大小合计约多少；大小未知的单独计数、明确写着「未计入」，不拿猜测凑总数。

## 审计（第 17 轮：设置与备份完整性）

- **设置矩阵全过**：把全部 30 余个设置项逐项核了四列——设置页有入口、代码真的读取生效、进备份文件、从备份恢复后真的应用（含设置页显示刷新）。绝大多数全过；**坐实并修了一个显示缺口**：恢复备份后，「开机后自动恢复」和「按类型分文件夹」两个开关的值其实已经恢复进存储了，但设置页的显示镜像没跟着刷新，页面上还是恢复前的样子，要重启 App 才对——现在恢复完立即同步。两个有意不进备份的例外不变并写明理由：下载目录（SAF 授权指向本机文件夹，换机不可迁移）、代理密码（凭证不进备份文件，恢复后需重填）。
- **任务字段往返全过**：任务的全部序列化字段——分片进度、镜像源、期望校验值与校验状态、单任务限速、每日定时、归档标记、备注、优先级、请求头——逐项过了「存盘 → 读回」和「导出备份 → 导入」往返，并新增一个常驻测试把整个字段集钉住，以后加字段漏了序列化会被测试当场抓住。导出备份剔除凭证的规则复核无误：Cookie、Authorization、Proxy-Authorization 三个请求头在导出时剔除（本机存盘保留，续传要用），其余请求头照常带走。几个有意的导入变换不变：备份里的「下载中」导入后落为暂停、校验中的落为未校验——都不会假装在跑。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。新设置（嗅探筛选记忆）不在老备份里时保持默认（类型全部、最小大小不限），不改变老行为。
- 没有新增任何权限；没有新增任何第三方依赖（重复检测用的是已有的 SHA-256 校验能力）。
- 安装包体积：以正式发布包实测为准（验收包约 1.3 MB 量级，仍在 1.5 MB 红线内）。
