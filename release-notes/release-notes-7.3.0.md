# TuxunDown v7.3.0

这一版没有新功能，专做一件事：把存在手机里的任务数据保护好。下载器最怕的不是下得慢，而是任务列表突然没了——下了多少、哪些下完、哪些还要接着下，全记在任务记录里。这一版把这份记录的损坏处理从头理了一遍：能自己救回来的就自己救，实在救不回来的也会明明白白告诉你，不再悄悄清空。

## 数据保护

- **主文件坏了，自动用备份恢复**：任务记录平时会留一份备份。主文件读不出来时，现在会自动改用备份恢复，任务列表不会凭空消失，你也不用做任何操作。
- **个别记录坏了，从备份补回**：如果主文件还能打开、只是里面有几条记录坏了，好的记录照常显示，坏掉的那几条会从备份里按编号补回来，不会因为一条坏了就少一条。
- **备份本身也不会被坏文件冲掉**：恢复之后第一次保存时，会先确认主文件是好的才更新备份，不会把刚救回来的备份又覆盖坏。
- **实在救不回，会保留坏文件并明说**：主文件和备份都坏了这种最坏情况，坏文件会先改名留在一边保存好，不会被新记录覆盖掉；主页也会弹出提示，把发生了什么、丢了什么说清楚，方便你决定下一步怎么办，不会假装什么都没发生。
- **分片记录的小毛病不再连累整条任务**：个别记录里的分片进度写坏时，现在只把那部分进度当作没下过，整条任务记录不会被一起丢掉。

## 诊断页「存储健康」

- 诊断页在「安全现状」下面新增一栏「存储健康」，打开就能看到每个存储现在的情况：任务记录有多少条、文件有多大、最后什么时候保存的、健康状态是正常还是自愈过；站点学习记住了多少个站、最近 7 天里有几天有下载记录、嗅探历史有多少条，也都列在这里。
- 设置读取出了问题、或者某个子存储解析时丢了行数，这里也会如实写出来：哪些设置回退到了默认值、合计丢了多少行，都能看到，不会藏着。
- 这一栏只报条数和健康状态，不显示任何具体内容；某一项读不出来时，只少那一项，其他项照常显示。

## 照例

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限，权限仍是原来的 10 项；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
