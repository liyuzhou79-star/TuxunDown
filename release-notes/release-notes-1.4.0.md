# TuxunDown 1.4.0

这一版先修了主页滑不动的老毛病，再一口气补上 20 项功能与体验改进，重点是任务多了以后也要管得过来。照例免费、开源、无广告，所有任务都在你的手机本地完成。

## 新功能

- **主页重做**：整页改成一个可滚动列表，从顶到底滑得通；设置独立成页，从主页右上角进入。
- **分类标签**：任务按全部 / 下载中 / 已完成 / 失败分开看，配合搜索和排序，大列表也不乱。
- **批量管理**：长按任务进入多选，可批量暂停、继续、插队、删除。
- **插队**：排队中的任务可以一键提到队首，先下它。
- **预约下载**：新建任务时可选 30 分钟后 / 1 小时后 / 3 小时后开始，到点自动开下。
- **任务统计**：展开任务详情能看到平均速度、峰值速度、总用时、分片数和重试次数；下完的任务还能回看当时的速度曲线。
- **同时下载数量可调**：设置里 1–5 个任务并行，通知栏会汇总显示总速度。
- **失败自动重试**：可选重试 1 / 3 / 5 次，间隔自动拉长，不用守着手动点。
- **流量保护**：用流量下载时可设上限（50 MB / 200 MB / 1 GB），超了自动暂停并写明，不会悄悄烧流量。
- **嗅探升级**：嗅探结果可多选批量下载、按类型筛选、按名称 / 类型排序；最近嗅探过的网页有历史记录，点一下重新嗅探。
- **浏览器悬浮按钮**：内置浏览器里悬浮一个下载按钮，当前页有文件就直接建任务，有多个资源就弹出列表让你挑。
- **下载前改名**：新建任务时可先填好保存文件名，不用等下完再改。
- **任务导入导出**：任务列表可导出成文件备份，也可从文件导回，换手机或重装不丢队列。
- **完成快捷动作**：下完的 APK 直接点安装，视频音频可直接播放，其他文件可打开或分享。
- **文件类型图标**：每个任务带彩色类型标记，APK、压缩包、视频、音频、图片、文档一眼分清。
- **空状态上手卡**：还没有任务时，主页会显示一张上手卡，两个入口直接开始第一次下载。

## 优化与修复

- **修复主页不能向下滑动**：原先主页是固定排版，设置卡把任务列表挤得只剩底部一条，现已整页重做（见上）。
- 深色模式逐页复查，旧的固定灰字全部换成随主题变化的颜色。
- 界面刷新节奏与速度采样对齐，滑动更顺、也更省电。
- 一处如实说明：嗅探结果在这一版还不带文件大小，所以排序做的是名称 / 类型；按大小排序需要的大小探测已在 1.6.0 补上。

## 说明

- 本版可直接覆盖安装在 1.2.0 及后续版本之上，不用卸载。
- 预约下载靠 App 在后台等时间，手机系统把 App 深度冻结时可能晚几分钟开始，属正常现象。
