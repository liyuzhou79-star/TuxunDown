# TuxunDown v3.0.0

3.0.0 是里程碑整合版：先把 2.1 到 2.9 的全部功能逐项回归核查了一遍（清单在下面），确认没有功能掉线、没有旧修复回退；再加两件新东西——下完自动解压 zip，和按时段自动换档的限速计划；帮助中心和 README 同步更新到 3.0。

## 新功能

- **下完自动解压 zip**（设置 → 提示，默认关）：开启后，.zip 文件下完会自动解压到它所在文件夹里、一个和压缩包同名的文件夹中，原 zip 保留不删。任务填了校验值（SHA-256 / MD5）时，要校验对上才会解压；没对上的文件可能已经损坏，不会替你拆开，完成说明里会写明没解压的原因。安全防线有两道：文件数（2 万）和解开后总大小（16 GiB）上限，防「压缩包炸弹」；压缩包里要是藏了想跳出目标文件夹的路径（../ 这类），整包停下、解出一半的文件清掉、原 zip 还在，并在卡片上把原因说清。解压进度和结果都写在任务的完成说明里。**只支持 zip**：rar、7z 等格式不会动——它们需要额外的原生解码库，本版不引入。
- **限速计划**（设置 → 下载）：在全局限速之上加一个每天的时段和时段内的一档限速。时段内全局限速自动换成计划档，时段外用回原来的全局限速；限速是每次计费时现读的，正在下的任务到了点自动切换，不用暂停或重启。典型用法：白天限速不抢全家带宽，夜间 23:00–07:00 设「不限」放开下。设置页里会直接写明「现在是否在计划时段内」。它和「通知静默时段」是两个独立设置：那个只管完成通知夜间不震动、不响铃，不管速度，互不影响。
- **帮助中心新增四个话题**：自动解压、限速计划、任务备注、队列预检——把这几个容易疑惑的功能讲清，全是离线内容。README 的功能列表同步补齐了 2.5 以来的功能（迅雷链接解码、快捷磁贴、分享清单、开机恢复、分类文件夹、任务备注、队列预检、限流学习、诊断页等）。

## 回归自检（2.1–2.9 全量核查）

把九个版本的功能点和历代审计修复逐项对着代码核了一遍，逐项确认「真的接上线、设置真的生效、修复没有回退」。结论：**全部在线，无一回退，本轮没有需要修的断线点**。重点复核项：

- **启动安全**：App 内图标全部用位图副本（v1.3 闪退的教训——自适应图标 XML 不能进 Compose 图片加载）；连崩安全模式（CrashGuard）接线在。
- **数据安全**：任务记录原子写（临时文件写完刷盘、旧文件留 .bak、再改名覆盖），读坏了自动回退备份；六代老数据迁移测试（v2.5 起常驻）继续全过。
- **下载完整性**：所有下载路径统一关掉 gzip 透明解压（防 Range 偏移错位）；分片逐片核 Content-Range 总长和主源强 ETag，服务器中途换文件会大声失败重验；HLS 分片验同步字节；连接在任何出口（出错、暂停、被淘汰、正常下完）都由 finally 释放（v2.7 修的长跑泄漏）。
- **速度系统**：收尾加速（最慢分片劈给空闲连接）、动态线程伸缩、按服务器记最佳连接数与限流上限、双栈连接竞速、空间预检，都在引擎主路径上。
- **入口与权限**：建任务只收 http / https / ftp（两个建任务入口都把关）；分享进来的文本有长度上限；WebView 文件访问保持关闭；磁贴、开机广播、小部件、FileProvider 的暴露面与 v2.8 审计结论一致；代理密码仍是系统钥匙串密文存储。
- **发布链**：Build Debug / Build Release 两个工作流的签名指纹断言都在（测试钥匙、正式钥匙各一份），正式包出包后另在本机复核指纹与版本号。
- **2.1–2.9 功能逐项**：单任务限速与全局预算的合成、完成自动安装/打开、桌面小部件、迅雷解码、静默时段与完成通知合并、延迟启动清扫、开机/被杀恢复、按类型分文件夹、快捷磁贴与全部暂停/继续、失败诊断建议、7 天下载量图、任务备注、队列预检、分享链接清单、自动校验开关与可取消校验、诊断页、帮助中心——逐个在代码里找到接线点核对。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。新设置（自动解压、限速计划）不在老备份里时保持默认关，不改变老行为。
- 没有新增任何权限；没有新增任何第三方依赖（解压用的是系统自带的 zip 能力）。
- 安装包体积：以正式发布包实测为准（验收包约 1.3 MB 量级，仍在 1.5 MB 红线内）。
