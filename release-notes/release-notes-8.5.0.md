# TuxunDown v8.5.0

这一版给已完成的任务添了「再下一次」：下过的文件想再要一份，不用再去翻链接、重新粘贴，直接在原来的任务上点一下就行；另外修好了深色模式下删除按钮红字看不清的问题，并把 7.7 版以来新增的界面做了一轮可用性复核。

## 新功能

- **已完成任务可以「再下一次」**：打开一个已完成任务的详情页，点「再下一次」；或者长按任务卡片，在菜单里选「再下一次」——都会按原来的链接、镜像和请求头新建一个任务，从零再下一份。要注意它和断点续传不是一回事：续传是接着没下完的地方继续，「再下一次」是另起一个新任务、完整地再下一份，原来那份文件原样保留。
- **新文件自动避名，绝不覆盖原文件**：再下的文件如果和已有文件重名，会自动存成「名字 (1)」这样的新名字，两个文件并排放在下载目录里，谁也不会把谁顶掉。
- **没有原始链接的记录没有这个入口**：通过文件页认领等方式生成的记录本身没有下载链接，也就没有「再下一次」可用；想再下需要把链接粘进来新建任务。帮助中心新增了话题「下过的文件想再下一份怎么办？」，把入口位置、和续传的区别、重名处理都讲清了，在帮助里搜「再下一次」就能找到。

## 修复

- **深色模式下删除按钮的红字看不清，已修复**：删除文件用的红色文字以前在深色背景上对比度不够、看着费劲。这一版改成深浅两套颜色：浅色模式用稍深一点的红，深色模式用更亮的红，两种模式下都达到文字看得清的标准。任务详情里的红色删除按钮和删文件确认弹窗里的红字都一并改了；其他地方的红色标记（比如状态点）不受影响。

## 照例

- 本轮把 7.7 版以来新增的界面逐项复核了一遍：详情页小按钮的触控面积（够大、不会误触）和大字体下的文字排版、统计页按主机学习数据的长站名换行与按钮可达、全程速度曲线的标注字号、诊断页新增几栏的长内容换行、设置页「尾巴双下」开关行的文字换行——除上面那处红字对比度外，其余都没有发现问题；详情、统计、诊断、设置四页在大字体、小屏幕下都确认能滑到底，不会再出现内容被截住滑不动的情况。
- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限，权限仍是原来的 10 项；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
