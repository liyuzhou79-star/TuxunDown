# TuxunDown v2.0.0

2.0.0 是一个整合版：把 1.2 到 1.9 一路加进来的全部功能逐项回归自检了一遍，同时接通了真正的检查更新、补上帮助中心，并把安装包又瘦了一圈。功能一个没砍，包反而更小。

## 新功能

- **检查更新接通了**：设置 → 关于 →「检查更新」，点一下就向 GitHub 查询最新正式版并在 App 里比对版本。有新版会显示更新说明，点「下载更新」直接用本 App 的引擎把新安装包下到公共「下载」目录，下完在任务卡上点「安装」即可升级。只在手点时联网查一次，平时不联网、不会自动下载。
- **帮助中心**：设置 → 引导与数据 →「常见问题」。为什么下载比浏览器快、为什么有时候快不了、单线程是什么意思、双通道需要什么条件、流量保护怎么工作、下好的文件在哪、续传靠什么接着下——七个最常见的问题，全是离线大白话，不用联网也能看。

## 优化

- **全量回归自检**：从 1.2 到 1.9 的每一项功能都重新核对了三件事——入口还在不在、点下去是否真的走到对应逻辑、设置改完是否真的生效。自检中发现的问题（包括检查更新此前只是打开网页）都在这一版里修好。
- **安装包瘦身**：换用更彻底的压缩方式，清理了没用到的库内容和调试残留，包体比 1.9.0 更小。
- **大字体适配**：系统字体调到最大档时，主要页面不再溢出、重叠；选项行放不下时可以横着滑，新手引导的正文可以上下滚动。
- **无障碍**：任务卡上的暂停、继续、删除按钮补上了文字说明，读屏软件能正确读出它们的作用。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 检查更新查的是 GitHub 上的最新正式版；如果你装的是比正式版更新的验收包，它会如实告诉你「你现在用的比发布页还新」。
