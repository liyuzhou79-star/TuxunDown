# TuxunDown v3.7.0

3.7.0 做两件看得见的新东西和一轮收尾审计：任务卡片的详情行可以自选显示了；失败任务多了一种批量重试法——先换「谈法」再排队。第 23 轮审计盘了全仓的用户可见文案和深色模式：引擎里重复了四份的提示话术收敛到一处，桌面小部件补上了深色适配。

## 新功能

- **任务卡片显示自选**（设置 → 任务卡片显示）：展开任务「详细信息」时显示哪些可选行，现在由你决定——平均速度、重试次数、分片进度（分片行＋分片图）可以关掉；创建时间、来源站点（链接的域名）是这一版新增的可选行，可以打开。默认与以前完全一致：原有的三项开、新增的两项关，升级后什么都不用动。这组开关同样进设置备份和完整迁移包。
- **换个方式重试**（多选任务，选中里有失败任务时出现）：有些失败不是链接坏了，是和服务器的「谈法」不对。批量给失败任务换浏览器标识（UA）——对付按 UA 区别对待的服务器（只认浏览器、防盗链挡下载工具之类），可选预置或选「默认」去掉任务自己的 UA；或者批量改成单线程重试——对付连接一多就不稳的服务器。改完统一重新排队，已下载的分片进度保留，不会白下。每个任务的卡片上会写明这次换了哪种方式。

## 修复

- **桌面小部件适配深色**：小部件的背景和文字颜色以前是写死的浅色，系统深色时桌面上永远是一块白底黑字。现在背景、进度轨道和文字都有夜间版本，跟随系统切换（进度绿不变）。

## 审计（第 23 轮：文案资源与深色二轮）

- **引擎话术收敛**：全仓盘点用户可见字符串。引擎的任务提示里，同一句话在分片、单流、流媒体、FTP 四条路径各写了一份（流量保护出现 5 次、仅 WiFi 暂停 4 次、存储不足 2 次、服务器中途换文件 3 次），这次全部收敛到一处（core/Notes），措辞逐字不变——包括「开始时已在流量上」和「途中切到流量」两种本来就不同的说法，各自保留。以后改话术只改一处，四条路径同时生效。新的单元测试把这几句的确切文字钉死，改词必须同时改测试。
- **不收敛的部分（核过，写明理由）**：界面文案（按钮、设置行、标签）按本项目的结构就写在界面代码里，错误句由 Errors 统一、失败建议由 FailureAdvice 统一、数字格式由 Format 统一，都已是单一出处；通知标题各自绑定一个系统通知位、更新日志是逐版历史文本，都不适合也不需要合并。
- **深色二轮逐屏核**：主题定义、进度条轨道、速度/统计图（本来就按深浅两套色画）、滑动手势标签（2.9 已修对比度）、扫码页（相机画面上的半透明黑条＋白字，是覆盖在摄像头画面上的设计）、嗅探页悬浮下载按钮（绿底白字，浮在网页上）逐项核过，没有写死的浅色背景。顺手删了一个没有任何地方在用的颜色定义。唯一坐实的就是上面已修的桌面小部件。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积：以正式发布包实测为准（验收包约 1.3 MB 量级，仍在 1.5 MB 红线内）。
