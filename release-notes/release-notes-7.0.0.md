# TuxunDown v7.0.0

7.0 是整合版：这一版没有新功能，做的是收尾——把 6.1 到 6.9 一整轮陆续加的功能全部回头核对一遍，确认个个都真的接通、真的能用；再做一轮发布前的总审，把版本号、更新检查、备份往返、安装包体积这些容易悄悄出问题的地方逐项核清；最后把说明文档和现在的实际行为对齐。如果你还在 6.0 或更早的版本，这一版也正好把这一整轮的收获一次补齐。

## 6.x 这一轮的收获（从 6.0 或更早升级的先看这里）

- **更懂发热了（6.1）**：一键体检多了「设备温控」一项；下载中手机发热降速时，下载通知里会多一行提示，说明慢可能不是网络的问题。提示只提醒，不会自动暂停你的下载。
- **任务卡更好用了（6.2）**：长按任务卡弹出快捷菜单，常用操作一步到位，多选入口在菜单末尾；统计页多了「最快纪录」前三名；大字体下 9 个弹窗改成可以滚动，按钮不会再被挤出屏幕。
- **粘贴链接更省心（6.3）**：新建下载时可以勾选先把短链接展开成真实地址（默认关，展开失败会用回原链接并说明）；复制链接后打开 App 的提示做了频控，同一条内容本次打开不会重复弹，上次最后提示过的那一条下次打开也不会再弹。
- **时间口径统一了（6.4）**：导出的报告、曲线、崩溃日志用同一套时间格式；每天定时任务会记下你选的几点几分，换时区或改系统时间后自动按新时区对准这个时间（这一版之前建的老任务没存下时间，仍会漂移，删掉重建即可）。
- **限制写明了（6.5）**：仓库里多了一份「已知限制」清单，把做不到的事提前讲清；嗅探结果长按会说明某条为什么不能下；图表上的坐标字号统一调大，看得清。
- **断网恢复更快了（6.6）**：默认网络一断，正在传的连接立刻失败走重试，不再等满超时；停泊等待期间除了系统事件，还有约 5 秒一次的轮询兜底，网络一回来就继续。
- **文件页能对账了（6.7）**：一键对账把「记录还在、文件没了」和「文件还在、记录没了」分开列出，每条都由你决定删记录、认领还是保留，绝不自动删；没有记录的文件可以认领为已完成记录，改过名的可以更新记录名；文件已不在的记录会明确标注，打开、分享按钮提前置灰。对账只查当前下载位置，授权失效时查不出的会标「无法确认」，不误报。
- **失败会通知了（6.8）**：下载彻底失败才发通知（自动重试还没用完的不发），普通失败可以直接在通知上点「重试」，需要先处理的会写清先做什么、不给重试按钮；短时间多个失败合并成一条，和完成通知分开，互不覆盖；失败通知任何时候都不震动、不响铃。设置页还多了「通知现状」一行，通知权限和静默时段状态一眼看清。
- **帮助补齐了（6.9）**：帮助中心补到 35 条话题，这一轮加的功能都有了对应说明；全局搜索多出「帮助」一组，搜问题能直接搜到话题，点一下直达定位。

## 本版的整合工作

- **全量回归自检**：6.x 一轮的 27 个功能点逐个从界面入口追到实现代码，全部接通——没有只写了说明却没接上的，没有哪个在后来的版本里被改坏。这一轮没有查出需要修的问题，所以本版没有改任何功能代码。
- **发布总审**：版本号从 1.2.0 到 6.9.0 共 58 个版本逐个核对，顺序严格递增、无跳号无重号，7.0.0 顺接其后；检查更新时新旧版本比大小的边界（比如 6.9 升 7.0、将来 7.9 升 7.10、9.x 升 10.0）逐个验证并补了专门的测试钉住；备份文件导出再导入做了完整往返核对，每个字段都对得上，密码、Cookie 这类敏感信息在往返之后仍然不进备份；安装包的体积守门复核无误。
- **文档总同步**：功能说明补清了两处——文件页的「文件已不在」标注和改名后更新记录名、剪贴板提示跨次打开的频控；帮助中心 35 条话题和「已知限制」19 条逐条复核，都和现在的实际行为一致，没有需要改的。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限，权限仍是原来的 10 项；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
