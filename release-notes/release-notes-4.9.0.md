# TuxunDown v4.9.0

4.9.0 主要做三件事：下载时保持处理器运行，息屏后大文件下得更稳；App 切到后台后界面不再每秒刷新，更省电；多个任务一起下载时，通知栏也会写明全部下完大约还要多久。没有承诺任何速度倍数，下面只讲具体改了什么。

## 新功能

- **息屏不降速（下载时保持 CPU 运行）**：以前文件下载靠前台服务保活，但息屏后处理器仍会睡过去，正在下载的线程和每秒的速度统计会被拖慢、拖晚，大文件在息屏时更容易变慢、变不稳。现在只要有任务真正在传输，就会保持处理器运行，息屏也能稳稳接着下；任务一结束就立刻放开。排队、等充电、等网络、等预约时间这些没有真正在下载的状态不会占用，也不会白白耗电。这个功能默认打开，设置里的「后台运行」一栏可以关掉，开关旁边会写清代价：开着更费电。
- **通知栏显示全部下完还剩多久**：以前只有单个任务在下时，通知才带剩余时间。现在多个任务一起下时，通知栏也会按所有正在下载任务的总进度写明「全部还剩 大约 X 分钟」，和主页汇总卡用的是同一套估算口径。有任务大小未知、或当前还没有速度时就不显示这个时间，不写假的精确数字。

## 优化

- **切到后台更省电**：以前 App 切到后台、界面已经看不见时，界面仍在每秒刷新一次，白白唤醒处理器。现在界面切到后台就暂停刷新，切回来会立刻刷新一次再继续；下载本身在后台服务里独立运行，不受这个改动影响，该下的照样下。

## 修复

- **息屏下载稳定性核对（稳定性）**：这一项把息屏和省电相关的代码过了一遍：确认了下载引擎没有忙等空转，连接的监督、速度采样和等待都是正常的休眠等待，息屏时被拖晚的根源就是处理器睡过去，所以才补上上面的保持运行；手机厂商系统冻结 App 的情况，设置里原有的电池白名单引导（状态说明、Flyme 路径、最近任务锁定步骤等）仍然有效，和新开关放在同一栏，保活的说明集中在一处。

## 说明

- **本版新增权限 WAKE_LOCK（唤醒锁）**：这是普通权限，安装时自动授予，不需要你手动允许。本版新增权限 WAKE_LOCK（唤醒锁），仅在下载传输期间用于保持 CPU 运行、息屏不降速，可在设置中关闭。除了这一条，本版没有新增、也没有去掉任何其它权限。
- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何第三方依赖。本版的唤醒锁计数、后台刷新暂停和通知剩余时间都有单元测试或代码核对钉住。
- 安装包体积：以正式发布包实测为准（仍在 1.5 MB 红线内）。
