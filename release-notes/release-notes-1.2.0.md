# TuxunDown 1.2.0

TuxunDown 正式版来了。免费、开源、无广告：一款专为安卓打造的多线程极速下载器，粘贴链接就能下，丢个网页进去还能自动把里面的资源找出来。没有账号，没有服务器，所有任务都在你的手机本地完成。

## 新功能

- **多线程分片加速**：一个文件会被切成多块、由多条连接同时下载。下载开始时自动试探最佳线程数（4 → 8 → 16 → 32，速度不再涨就停），下得快的连接还会回头帮最慢的那块，不被单条慢线拖住全场。实测同一个 271 MB 大文件：浏览器单线程约 300 KiB/秒，TuxunDown 跑到约 6 MB/秒，**约 20 倍**，15 分钟的等待缩短到 1 分钟以内。
- **资源嗅探**：丢进去的不一定非得是直链。把下载页的网页链接粘进来，会自动列出页面里的安装包、压缩包、视频、音频、文档等资源，勾选即可下载；遇到要点一次「下载」才跳到真实文件的中间页，会顺着唯一的路径自动追到底；实在追不动的页面，还有内置浏览器，手动点到下载那一步，它会接住真实地址继续下。
- **断点续传与任务队列**：暂停、关掉 App、断网都不怕，回来接着下；多个任务自动排队，也能随时暂停和继续单个任务。
- **仅 WiFi 下载**：打开后流量网络下任务只排队不启动，不偷跑流量。

## 优化

- **传输表达全面对标电脑端**：进度和速度的呈现方式照着电脑上传输文件的窗口重做了一遍——绿色进度条带流动高光、暂停变黄、出错变红；下方是 90 秒速度曲线图，绿线加绿色填充，当前速度、峰值速度、剩余时间、已下载大小一目了然。几个任务同时下载时，顶部还有总进度汇总，通知栏里也是同一套表达，不用打开 App 就能看。
- **文件直接落在公用下载目录**：下载完成的文件和没下完的半成品，都直接放在系统「下载」目录里，文件管理器随时可见、可用真实文件名打开和分享，不藏在应用的私有角落；也可以在设置里换成任意自选文件夹。
- **直链和网页自动分流**：粘贴后先探测对面是文件还是网页，是文件直接开下，是网页才去嗅探，不再走错路；嗅探失败会把原因说明白（被拦截、页面里没有资源等），不留空白让人猜。
- **诚实的限速提示**：如果服务器按 IP 总限速或不支持分片，多线程提不了速时会自动退回单线程，并在界面上写清原因，不假装加速。

## 说明

- 本版起改用正式签名：装过测试版的用户需要先卸载再安装这一次，之后所有版本都可以直接覆盖升级。
- 提速幅度取决于服务器：对单条连接限速的服务器效果最明显（常见于各类直链大文件）；如果服务器本身按总量限速，或你的网络带宽已经被单线程跑满，任何下载器都无法再快——这时 App 会如实提示。
- 本版暂不包含磁力/BT 下载和网盘分享页解析，后续版本会再评估。
