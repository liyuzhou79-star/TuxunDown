# TuxunDown v6.0.0

6.0.0 是 5.x 这一整轮的整合版。这一轮先把速度和稳定打磨到位，再回头做了一次彻底的总检查：4.1 以来的功能逐项对着实际代码复核是否真的接通、升级到这一版的每条路径提前核查、说明文档和 App 内帮助全部同步到最新功能。下面先讲 5.x 这一轮实际交付了什么，再讲这一版自己的总检查结果。

## 新功能

- **任务详情「连接预算」行（5.9）**：正在下载的任务，详情里会写明它当前分到了多少条连接，以及这个数字是被什么压住的——所有任务合计的全局连接上限、这个站点以前限流过留下的上限，还是单个任务自己的上限。数字跟着实时刷新，实际在跑的连接数还在爬升、暂时没跟上时也会如实标出；排队、暂停或已完成的任务不显示这一行，不拿假数字糊弄人。
- **诊断页一键体检（5.5）**：版本与签名、内存、启动耗时、下载空间、网络、域名解析、学习数据和任务状态九项汇成一页，点了才跑，结果可以复制下来报障用。
- **镜像状态看得见、待确认可手动放行（5.4）**：任务的每个镜像都按已有的校验记录标明已确认、待确认、已拒绝或还没校验；没能确认的镜像可以手动放行让它参与多源下载（只对这个任务有效、随时可取消），已经证明是别的文件的不能放行。
- **自动读取校验文件（5.8，设置里默认关）**：打开后，新建下载会顺手找网站放在文件旁边的 .sha256 / .md5 校验文件，下完按网站给的值核对，并在卡片上写明这个值来自网站的校验文件；关着的时候不发任何这类请求。
- **嗅探历史重新嗅探（5.7）**：嗅探历史每条旁边多了「重新嗅探」按钮，点一下就用原来的网页地址重新抓一遍，成功后这条挪到最前面；抓失败时原来的历史和上次结果都原样保留，不会因为一次失败把之前的结果弄丢。

## 优化

- **连接起速更平滑（5.3）**：新任务和多任务同时开始时，连接数平滑爬升，不再短暂冲过全局上限；上限调低仍然立即生效。
- **双预算调度的口径核实并讲清（5.9）**：连接数和全局限速是两套分配——连接按全局上限和优先级分，带宽按优先级切分且每个任务都有保底份额。任务结束、暂停或新任务加入后，带宽份额在下一次写入时就重新分配，连接数最快几秒内跟上，边角情况下最多约十秒，不需要重启任务。某个任务暂时用不完自己那份带宽时，份额不会转借给别的任务，这是为了保证谁都不会被饿着的有意取舍，不是卡住了。
- **重试等待自动错峰（5.8）**：多个任务或多条连接同时失败时，重试等待会随机错开，不再齐刷刷在同一时刻一起重试；每次等待只会更短，所有上限和最长总等待都没有变长。
- **建任务全面去重（5.4）**：同一链接只要还有未完成的任务在列表里（排队、下载中、暂停、失败都算，主地址或任一镜像对上都算同一个），从主页、嗅探、扫码任一入口都不会重复建；批量导入会明说跳过了几个；已经下完的历史不拦，想再下一份照样可以。
- **说法四处统一（5.3）**：任务卡片、通知栏、桌面小部件和快捷设置磁贴用同一套状态说法——失败就叫失败、全在排队时就说排队中，连接数显示实时条数，哪个地方都不会换个说法让人猜。

## 修复

- **测速改走代理（5.9）**：以前配了代理时，内置测速和连接数对比实测会绕过代理直接连，测出来的数字跟实际下载走的路不是一条，有些只能通过代理访问的地址还会测出 0；现在测速和下载走同一套代理设置。测速页也补上了提醒：测速不会暂停正在下载的任务，有任务在下时结果会偏低，测速开始时会记下当时有几个任务在下并在结果里说明。
- **嗅探深水区修复（5.7）**：响应式图片组（srcset）和脚本数据里转义过的媒体地址现在也能抓到；file:、blob: 这类根本下不了的假链接不再混进结果列表，在浏览器里点到时会直接说明原因；同一个文件用不同写法链接（大小写、默认端口、锚点不同）现在合并成一行，不再重复出现。测大小时对同一个站点最多同时测 3 个，不给对方添堵；在内置浏览器里嗅探到的需要登录的文件，现在会带上浏览器里的登录状态，不再白白失败。
- **校验值录入更宽容（5.8）**：从发布页整行复制的校验值——带文件名、带算法前缀的——现在都能认；校验进行到一半改了期望值时，旧值的结果不会错记到新值头上；删掉正在校验的任务会先停下校验，不再白读一遍大文件。

## 说明

- **这一版的总检查（6.0）**：全量回归把 4.1 到 5.9 的约 57 个功能点逐个追到实际调用处复核，结论是全部接通，没有断线、没有回退、没有只写了说明没有实装的条目；此前各轮审计的修复点也抽查复核，都还在。发布就绪审计核了五件事：从 1.2.0 到这一版的版本号链逐个连续、没有断档或重复；检查更新的版本比较在 5.9 升 6.0、6.0 升 6.10、6.9 升 6.10 这些跨位情况下都算对，并加了自动测试钉住；关于页、新手引导、诊断页和一键体检显示的版本号与签名指纹都来自同一个运行时读数，不会各说各话；近几版的发布说明逐条对过代码，没有夸大；备份的导出再导入往返核过，设置、任务、统计和按站点学习数据都能原样回来，旧版备份照常能导。
- **文档与帮助总同步（6.0）**：帮助中心新增六个话题（连接预算、自动读取校验文件、建任务去重、镜像待确认与手动放行、嗅探历史重新嗅探、一键体检）；仓库说明补上了完整的权限清单——一共 10 项，每项写明用途——和安装包体积说明。
- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
