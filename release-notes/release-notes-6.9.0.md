# TuxunDown v6.9.0

这一版没有加新下载功能，做的是把说明补齐、把搜索补全：6.1 以来陆续加的功能（长按菜单、最快纪录、短链接展开、一键对账、失败通知……）在帮助中心里一直没有对应的话题，遇到问题只能靠猜；全局搜索也搜不到帮助。现在这两处都补上了，顺带把几处和实际对不上的说法改准。

## 新功能

- **全局搜索能搜帮助话题了**：主页搜索框的结果多出「帮助」一组，搜任务、文件、嗅探历史的同时也会搜帮助中心的话题标题和正文，标题对上的排在前面。点任意一条帮助结果，会直接打开帮助中心并定位到那个话题，不用自己从头翻。
- **帮助中心新增 8 条话题**：长按任务卡能做什么、多选任务怎么进、统计页的「最快纪录」是什么、短链接要先展开吗、复制链接后打开 App 时的提示是怎么回事、下载失败了会通知我吗、文件页的「一键对账」是什么、有哪些已知的限制——每条都按现在的实际行为写清，包括像「对账只报告、绝不自动删文件」「失败通知任何时候都不震动不响铃」这类容易误会的点。最后一条「有哪些已知的限制」是仓库里那份完整限制清单的浓缩版，帮助中心本身不联网，离线也能看；完整版仍在仓库 README 的「已知限制」页。
- **6 条旧话题补清**：双通道的话题补上流量保护的例外条件；每天定时任务的话题补上换时区、改系统时间后会按你选的时间重新对准（这一版之前建的老任务没存下时间、仍会漂移，删掉重建即可），以及春季跳时那天的一次性提前；静默时段的话题补明失败通知不归静默时段管；「下载中保持运行」补上改动约一秒即时生效；断网恢复的话题补上停泊约 5 秒轮询兜底和连接即时失败走重试；一键体检的话题补上下载中发热降速时通知里会多一行的提示。

## 修复

- **多选提示条的说法改准了**：多选时顶部的提示条以前写「长按任务卡可多选」，但从 6.2 起长按打开的是快捷菜单，这句话和实际对不上。现在写明：长按任务卡打开菜单，菜单末尾可进多选。
- **双通道的说明改准了**：设置里双通道开关下面的注文以前写「开双通道等于你同意用流量下载，流量保护不会再拦」，说得太满——实际上只有双通道真正生效时流量保护才不拦，授权没成功、任务仍走单网络时照样拦。现在注文改成「双通道真正生效时……」，和实际行为一致。
- **「已知限制」页同步了两处**：新增一条对账范围的说明（一键对账只查当前下载位置；文件夹授权失效时查不出的记录标「无法确认」，不误报）；「全局搜索只能搜到有任务记录的文件」一条的枚举补上了帮助话题，和搜索现在的四组结果对齐，这条限制本身的结论没有变。

## 说明

- 本版发布前做了一轮文案与实现的一致性审计：帮助中心全部话题、设置页 30 项开关与说明、日志与导出文案、已知限制全部条目都逐项和代码核对过。结论是设置文案与行为一致、没有发现夸大承诺；发现并修掉的与实际不符的说法，就是上面修复里列的那几处，其余缺的说明都在帮助中心补齐了。
- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限，权限仍是原来的 10 项；没有新增任何第三方依赖。
- 安装包体积以本页附带的正式包实测为准，并继续受 1.5 MB 体积守门约束（超过就发不出来）。
