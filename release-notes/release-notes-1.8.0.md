# TuxunDown 1.8.0

这一版做第二轮提速和一批体验补齐：开下更快、通知栏能直接操作、测速有了自己的页面、备份能整机搬走。照例免费、开源、无广告，所有任务都在你的手机本地完成。

## 新功能

- **内置测速页**：统计页里可开始测速，单连接和多连接各测一段并排对比。页面会提前讲清：测的是你的手机到测速服务器的速度，大约消耗 10–100 MB 流量。
- **通知栏操作**：下载通知带暂停 / 取消按钮，不用打开 App；多个任务同时下时，通知会汇总列出每个任务的进度和速度。
- **任务卡滑动手势**：卡片左滑暂停 / 继续，右滑删除（会先弹窗确认，不会误触删掉）。
- **每日定时下载**：任务可设成每天固定时间自动下，适合蹲每天更新的资源。
- **整机备份恢复**：设置和任务可以打成一个备份文件导出，换手机或重装后一次导回；老版本的任务备份文件仍然能导入。

## 优化与修复

- **开下更快**：探测和续传预检改成并行进行，少了几趟网络来回，从点下载到真正出速度的时间缩短。
- **分块按文件大小分档**：小文件少切块、大文件细切块，记账开销和尾巴拖延都更合理。
- **完成封口更稳**：文件下完和任务保存时都强制落盘确认，断电也不容易出现「显示下完、文件却缺一截」。
- 审计一轮修掉 6 处毛病，包括 FTP 退出时可能卡住半分钟、通知在多个任务时数字对不齐等问题。

## 说明

- 本版可直接覆盖安装在 1.2.0 及后续版本之上，不用卸载。
- 每日定时和预约下载靠 App 在后台等时间，手机系统深度冻结 App 时可能晚几分钟，属正常现象。
