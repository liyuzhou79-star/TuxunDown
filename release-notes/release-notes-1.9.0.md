# TuxunDown 1.9.0

这一版主要是把「下完之后」和「特殊网络」两头补齐：新增已下载文件管理页、下载代理、每任务请求头编辑，嗅探结果也更清爽了。照例免费、开源、无广告，所有任务都在你的手机本地完成。

## 新功能

- **已下载文件页**：主页新增入口。下好的文件集中列出（包括以前删过任务记录、只剩下文件本体的），按时间或大小排序，顶部显示文件数和占用总量；每个文件可打开、分享、删除。删记录和删文件是两个分开的动作，各自确认，不会误删。
- **下载代理**：设置里可填 HTTP / SOCKS5 代理（主机、端口，可带用户名密码），下载和嗅探都走它，正在走代理的任务卡片上有标记。代理连不上时，任务会停下来并写明原因——绝不悄悄改走直连。两个例外会提前讲清：FTP 链接和内置浏览器打开网页本身不走代理（协议与系统限制），浏览器抓到链接后建的下载任务走代理。
- **每任务请求头编辑**：任务卡详情里可以查看、修改这个任务带上的 Cookie / Referer / User-Agent 等请求头，一行一个，写错格式的行会当场指出，不会悄悄改掉。改完对续传生效；从浏览器抓到的任务如果 Cookie 过期，在这里换上新的就能接着下。
- **嗅探结果再升级**：统计、广告、小图片这类噪音资源默认折叠，需要时一键展开；名字和大小都一样的资源会标上「可能重复」，避免同一个文件下两遍；嗅探结果关掉不再丢失，主页有「上次嗅探结果」入口，点开接着选，不用重新嗅探和重新测大小。
- **内置浏览器长按下载**：在内置浏览器里长按任意链接，可直接把这个链接交给 TuxunDown 下载（带当时的 Cookie 和来源页），不用等页面自己触发下载。

## 优化与修复

- **备份更稳妥也更安全**：导入备份加了文件大小上限和逐条内容校验，损坏或被动手脚的备份文件搞不崩 App，一条坏记录也不会连累其他记录；导出时每个任务的 Cookie 和代理密码会被自动剔除，备份文件可以放心保存。
- **分享链接更顺手**：往已经打开的 TuxunDown 分享链接时，不再开出第二个界面，链接会直接填进新建下载框。
- **内置浏览器加固**：页面想跳去非网页链接（intent://、tel: 等）会被拦下并说明；转屏后页面和进度会恢复，不用重新点一遍；抓到 blob: 这类下不了的「下载」会直接说明，不再建一个必然失败的任务。
- **扫码更稳**：扫码页切出去再回来，相机预览会自动恢复，不会黑屏到重开。

## 说明

- 本版仍为验收节奏中的版本，正式发布页以 GitHub Releases 为准；可直接覆盖安装在 1.2.0 及后续版本之上，不用卸载。
- 代理只改变网络走向，不改变下载逻辑：服务器按总量限速时，用不用代理都不会更快，App 会照常如实提示。
