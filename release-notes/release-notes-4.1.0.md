# TuxunDown v4.1.0

4.1.0 做五件事：把连接复用的账清完（探测类连接也回池）、给「不老实」的服务器逐项上防护、桌面小部件加上全部暂停 / 继续、内置测速留历史、完成通知补上文件大小和平均速度。前两件是看不见的底子功夫：起步少付握手，遇到报假大小、给错起点的服务器也不会把坏文件当成下完交给你。

## 修复

- **流媒体分段被截断不再当成下完**：以前下载 m3u8（HLS）时，单个分段如果只给了一半就断开，没有和它声称的长度对过账，残缺分段会被合并进去、整个任务还标成完成。现在每个分段（包括播放列表本身）下完都核对实际长度，对不上就走原有的重试，重试还不行就报错停下，不交残缺文件。
- **单线程与 FTP 下载拦住「给多了」**：以前这两种下法对服务器多给的内容不设防——声称的大小是一回事、实际塞过来的字节只多不少，最后照样按完成处理，多出来的内容会把文件写坏。现在边下边核对：超过声称的总大小立刻停下报错；FTP 下完还要求字节数分毫不差才算完成。
- **206 起点不对一律拦下**：分片下载要求服务器「从第 N 个字节开始给」，有的服务器会给错起点甚至干脆不说起点。以前有一处校验在服务器不给位置信息时就跳过了，错位的内容可能被写进文件。现在三处相关路径统一口径：起点和要求的不一致（包括没给起点信息）就拒绝这一段、重试处理；镜像校验和测大小的探测同样加了起点核对，对不上的镜像直接判不合格；探测阶段发现起点不对劲的，会稳妥降级成单线程下，不拿错位数据冒险。

## 优化

- **连接复用清账，探测连接也回池**：上一版分片下载的内容连接已经改成读完回连接池复用。这一版把剩下的连接逐个过了一遍：测文件大小、镜像校验、嗅探（含逐跳探测和量大小）、检查更新、内置测速——这些先头连接只要把内容完整读完，同样放回连接池给后面的下载接着用，少付一轮连接建立和加密握手，起步更快。少数故意不断开的情形也逐处核过：内容没读完、来路不明的响应体、跳转中间跳、卡死淘汰的连接，该断的仍然断，不拿半截数据冒险。

## 新功能

- **桌面小部件加「全部暂停 / 全部继续」按钮**：小部件的状态行上多了一个按钮，和主页汇总卡、通知栏磁贴是同一套逻辑——有任务在下时显示「全部暂停」，有任务停着时显示「全部继续」，不用打开 App 就能操作；没有可操作任务时按钮自动隐藏，不占地方。深色模式下按钮样式同步适配。注意：内容变高了，小部件高度从一行格改成两行格，已经摆在桌面上的小部件如果显示不全，删掉重新添加一次即可。
- **测速留历史**：内置测速（单点）每次测完，结果自动存进测速页下方的历史列表：时间、测速点、单线程和多线程速度、当时的结论，最近 10 次。换个时间、换个网络再测，能直接和上次对比。历史只存在本机、不进备份（换手机不会带过去），列表旁有一键清空。多点对比测速口径不同，不记入历史。
- **完成通知带大小与平均速度**：单个任务下完的通知，展开后多一行「大小 · 平均速度」——平均速度就是任务卡片和统计页用的同一个数（只算真正在传的时间，暂停等待不计入）。多个任务一起完成、合并成一条通知时，如果每个文件的大小都知道，正文会标出总大小；只要有一个大小未知，就不标总数，免得标个偏小的数误导你。折叠状态的通知和以前一样，没有变化。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。本版的防护判断、历史存储、通知文案都是纯逻辑，带单元测试（含长度对账、206 起点、历史存取、通知文案的边界用例）。
- 安装包体积：以正式发布包实测为准（仍在 1.5 MB 红线内）。
