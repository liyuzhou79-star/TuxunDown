# TuxunDown v2.5.0

2.5.0 做了三件事：一轮「升级迁移」专审（第 11 轮）——把从 1.2 到 2.1 每一代的老数据都造出来实测，确保老用户升级上来任务和设置不丢不乱；迅雷链接解码——thunder:// 链接现在能直接粘进来用；通知批——完成通知带「打开 / 分享」按钮、多个完成自动合并、新增夜间静默时段。另外启动路径再梳了一遍，打开更快。

## 升级迁移专审（第 11 轮）

- **每一代的老任务记录都实测过**：按 1.2 / 1.3 / 1.4 / 1.6 / 1.7 / 2.1 各代写入记录的实际字段，逐代造出当年的 tasks.json 喂给现在的读取代码，断言不崩、不丢任务、关键字段不串味：分片断点位图（决定续传从哪接着下）逐位对齐、半成品文件的目标位置（targetUri）原样保留、1.7 起的期望校验哈希（SHA-256）不丢、流媒体任务已写分片的前缀和镜像地址不乱。这套测试已经常驻，每一代老数据以后都会被自动回归。
- **格式为什么能对得上**：任务记录的格式从 1.2 起只增不改——没有任何字段被改名、改类型或删除；分片位图的编码方式从 1.2 起逐字节未变；后加的字段在老文件里缺失时都落在明确的默认值上。混着各代记录的一个文件也能整表读入。
- **设置项同样过了一遍**：每个设置键自引入起，键名、存储类型、出厂默认值在后续所有版本里都没变过；唯一一次存储形式变化（代理密码改为加密存储，2.3）自带首次读取自动迁移。另外从 1.5 起所有设置读取都有类型兜底：万一某个值被写成错误类型，读到的是默认值而不是闪退。
- **结论**：从任何一个旧版本直接覆盖升级到这一版，任务、断点、设置都保留；不需要卸载重装，也不需要先导出备份。

## 新功能

- **迅雷链接解码**：thunder:// 链接本质上是一层外壳——把真实地址编码后包起来。这一版在所有入口（新建粘贴、批量粘贴、分享进来、剪贴板提示、扫码、从 .txt 文件导入）都会先把外壳解开、拿到真实的 http / ftp 地址，再走正常的探测和下载流程，和直接粘贴真实地址没有任何区别。解不开的链接（内容损坏、或里面包的不是网址）会明说解不开，不会假装在下。如实说明：这只是「解码」——ed2k、磁力链接需要专门的客户端协议，本 App 没有这个能力，包着这类地址的迅雷链接会被明确拒绝，不会假装支持。
- **完成通知带动作按钮**：下载完成的通知现在独立成一条（以前会被下载进度通知顶掉、服务一停就消失），上面直接有「打开」（安装包是「安装」）和「分享」按钮，文件下完在通知栏就能处置，不用先进 App 找卡片。
- **多个完成合并成一条**：一批任务在短时间内接连完成时，第一条照常发，之后完成的会合并进同一条汇总通知（点开能看到每个文件名），不再连着震十下、堆一墙通知。
- **通知静默时段**（设置 → 提示，默认关；默认时段 23:00–07:00）：开启后，这个时段里下载完成不震动、不响铃；完成通知照常出现在通知栏里，早上起来点开就能打开文件。时段可以跨午夜设置。

## 优化

- **冷启动再梳一遍（第二轮）**：盘点了启动时到底加载了什么——任务列表本身就是首屏，必须同步读；统计、站点线程记忆、嗅探历史这些本来就是用到时才读的，不占启动时间；上一版加进启动路径的「自动归档清扫」对首屏没有任何用处，这一版挪到了首屏显示之后在后台慢慢做。崩溃自救的安全模式也和这批对齐了：安全模式下这批可推迟的工作整批跳过，救援启动只跑最必需的东西。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 安装包体积：以正式发布包实测为准（验收包约 1.27 MB 量级，没有变臃肿）；没有新增任何第三方依赖。
