# TuxunDown v3.2.0

3.2.0 做三件新东西和一轮审计：多选任务可以批量改名了；测速页从单点升级为多点对比；嗅探结果可以导出成 .txt 清单存下来、随时整批导回来。第 18 轮审计是故障注入——把「每种下载状态 × 进程被杀 / 断网 / 存储满 / 服务器中途消失」逐格核了一遍，修了两个会导致「假完成」的真问题。

## 新功能

- **批量改名**（主页多选）：长按任务卡进入多选，选中几个任务后点「批量改名」。规则有四件：查找、替换为（都是纯文字匹配，不是正则，替换作用于整个文件名、扩展名也算）、前缀（加在最前）、后缀（加在扩展名之前，比如 movie.mp4 加 _hd 变 movie_hd.mp4）。确认前有逐个对照预览：新名字是什么、哪些不变、哪些不改，一目了然。**只改还没下完的任务之后保存时用的名字**：排队中、已暂停、失败的可以改；正在下载的和已完成的不会动，已经下好的文件更不会被改名。改完出现重名不用担心——保存文件时本来就会自动挑第一个空着的「名字 (1)」落盘，永远不覆盖别人的文件。规则若会把某个名字改空，这个任务保持原名。
- **测速多点对比**（测速页）：原来的快速测速保留（用第一个能连上的测速点测单线程 vs 多线程）。新增「多点对比」：把三个测速点——Cloudflare 测速节点、kernel.org 镜像站、CacheFly 测速文件——依次各测一遍单线程和多线程，结果画成一张同比例柱状图、逐点列出数字。**开跑前先报账**：全程约 30 秒、预计消耗约 30–300 MB 流量（网速越快用得越多），你点了确认才开始，中途可停。页面上也写明了为什么三个点的数字不能直接比快慢：它们在不同的网络上、到你手机的线路各不相同，数字只能看个大概；同一个点内部单线程 vs 多线程的对比才是重点。某个点连不上会如实记为「没测通」，不拿别的点的数据顶替。
- **嗅探清单导出**（嗅探结果对话框）：新增「导出为 .txt 清单」——勾了资源就导勾选的，没勾就导当前列表（筛选后的）。文件以固定名字存到下载目录（重名自动加 (1)），内容就是链接清单：每个资源一行文件名、一行链接。格式与主页分享出去的链接清单完全一致，所以两个入口互相通吃：导出的清单之后用「新建下载 → 从 .txt 文件导入」就能整批建回来，也可以把文件发给别人、发到另一台手机上导入。

## 审计（第 18 轮：故障注入矩阵）

把任务的每种状态（排队中 / 分片下载中 / 单线程下载中 / 校验中 / 流媒体合并中 / FTP 下载中）和四种故障（进程被杀、断网、存储满、服务器中途消失）交叉逐格核了重启后的状态自洽性。多数格子本来就成立（依据见下），修了两个真问题：

- **修：半成品文件被动过之后，旧进度会被误信（分片 + 流媒体合并，两处）**。续传进度的一半在任务记录里（哪些块下完了），另一半是公共下载目录里那个 .part 文件本身。如果 .part 的内容被文件管理器删掉、被清理工具就地截断、或被同名空文件替换（文件本身还在、任务记录指的还是它），旧代码只认记录不认文件：分片路径会把没写过的区域当成已完成，流媒体合并会把新分片写进空文件的中间、前面全是空洞——两种都会把缺了字节的文件报告为「下载完成」。现在两条路径在续传前都先量一次 .part 的实际长度和进度对账（分片文件在开始时就被预设为完整长度，短了就是丢了字节；合并文件只会越写越长，短于已合并进度就是丢了字节），对不上就作废旧进度、从头下，并在卡片上写明原因。量不到长度时（个别文件夹授权量不出来）不冤枉任何进度——量不到不等于丢了。
- **修：存储满在几条路径上会被说成网络问题**。分片路径早就对存储满有专门话术（「清出空间后点继续即可续传」），但流媒体合并、单线程、FTP 三条路径写盘失败时走的是通用错误翻译，会说成「网络或读写出错，可以换个网络」——照着做只会白忙。现在四条路径统一：真是存储满就直说存储满。
- **核过成立的格子（摘录）**：进程被杀——下载中的任务重启后落为暂停并带「被系统中断」标记，可自动恢复续传，进度按分片位图从落盘值重算，不多算一字节；校验中被杀——校验状态落盘读回时复位为「未校验」，绝不会留下假的对上 / 对不上结论（文件本身已改名完成，「已完成」属实，校验可以手动再跑）；断网——失败按网络错误停泊等恢复，不烧自动重试次数；服务器中途消失或换文件——续传前有 ETag / 大小复核，下载途中每个分片响应都核总长和校验标记，换了文件会大声失败、不会混拼；存储满——分片位图与进度保持自洽，清出空间点继续即续传；流媒体合并中被杀——已合并的是严格的前缀，分片指纹不变才续，指纹变了（播放列表内容变了）整场作废重来。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。本版没有新增设置项，没有行为默认值变化。
- 没有新增任何权限；没有新增任何第三方依赖（测速用的还是系统网络类，批量改名和清单导出都是纯本地处理）。
- 第三个测速点 CacheFly 的测试文件地址在加入前已实测可用（2026-11-22：返回 200、支持分段读取、真实数据可读）；测速点将来若失效，多点对比里会如实显示「没测通」，快速测速会自动换下一个点。
- 安装包体积：以正式发布包实测为准（验收包约 1.3 MB 量级，仍在 1.5 MB 红线内）。
