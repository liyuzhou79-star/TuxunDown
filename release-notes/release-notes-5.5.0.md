# TuxunDown v5.5.0

5.5.0 这一版主要做了两件事：诊断页新增了一键体检，九项状态汇成一页、点了才跑、结果能复制；同时给下载核心做了一轮全面检查，把关键判断补上自动检查、拆掉没用的旧代码，让它跑起来更稳。下面只讲具体改了什么，不承诺速度倍数。

## 诊断页一键体检

- **九项状态一页看全**：打开设置里的诊断页，最上面就是「一键体检」。它查九项：版本与签名、内存档位、上次启动耗时、下载空间、当前网络与开关门状态、代理连通（配了代理才有这一项）、域名解析、学习数据条数、任务总数和异常数。每一项前面有状态点，旁边还写明「正常」「注意」或「异常」，不只靠颜色区分。
- **点了才跑，不自动检查**：进诊断页时什么都不会跑，每一项都老老实实写着「未检查」；点「开始体检」后才一项一项查，查到哪项哪项亮起来。平时不用，它不会在后台自己动。
- **有两项会发出很小的网络请求，先说清楚**：九项里只有代理连通和域名解析需要联网——代理连通是试着连一下你配的代理服务器，域名解析是试着解析两个常用网址；其余七项都在本机完成。页面上在开始前就把这件事写明了，不会背着你联网。没配代理时，代理这一项干脆不出现，也不会去连一个没配过的地址。
- **结果可以复制，敏感信息会先脱敏**：查完点「复制体检结果」，九项结果就是一段可以直接粘贴发送的文字。复制前会过一遍处理：网址只留站点和路径、参数去掉，密码、口令这类值不会带出去。下载出了问题要找人看时，把这段发过去，对方一眼就能看出卡在哪一项。
- **和下面原来的自检分工不同**：诊断页下面原有的「开始自检」还在，它是更细的逐项检查，会实测写盘速度、逐项列出结果；一键体检是汇总速览，想快速看一眼整体状态用它，想细查用自检。这一版把两处介绍文字也对齐了：没配代理时两边说法一致（自检写明未开启直连，体检不列这一项，是同一回事），空间读不到时体检也会提醒先看手机总空间，不再只说一句读不到。

## 稳定性打底

- **关键判断补上了自动检查**：这一版把下载核心里几个要紧的判断逐个核对了一遍——文件写到哪个位置、下载失败算哪一类、代理密码的加密标记、任务优先级怎么读——都补上了自动检查，以后改代码时这些判断要是被改坏，检查会当场拦下，不会等到下坏文件才发现。
- **拆掉了没用的旧代码**：全仓重新扫了一遍，把确认没有任何地方在用的旧函数和一份与界面重复的旧清单删掉了。删的都是核实过确实没人用的部分，功能没有减少，包也更干净。
- **连接开销核算过，结论是够用**：顺带把多任务、多连接同时跑时的开销算了一遍账：五个任务、每个任务拉满连接时，每秒的统计和排序量都很小，没有哪把锁会长时间占着不放，不需要为此改动下载方式。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 没有新增任何权限；没有新增任何第三方依赖。
- 安装包体积：以正式发布包实测为准（仍在 1.5 MB 红线内）。
