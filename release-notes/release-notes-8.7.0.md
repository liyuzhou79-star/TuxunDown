# TuxunDown v8.7.0

一个急修版，只修一件事：**已下载的文件删不掉**。

## 修复

- **详情页和文件页删文件，改走系统确认删除。** 之前在部分手机（Android 11 及以上）上，公共「下载」目录里的文件直接删除会被系统拒绝，只能看到「没删掉，系统没有允许删除」。现在先试直接删；删不掉时，系统会弹出一个删除确认框，你点确认后由系统完成删除。
- **结果说得更清楚。** 删除后会再核对一遍文件到底还在不在，三种结果分开说：删成了、你取消了（文件和记录都原样保留）、还是确实删不掉，不会再把「取消」说成「失败」。
- 文件页的单个删除和重复文件批量删除同样走这条新路；批量删不掉的多个文件只弹一次确认框。

## 说明

- 这是系统层面的限制，不是文件损坏：新版安卓对公共目录里文件的删除有更严的规矩，必须由你在系统弹窗里亲手确认，任何应用都绕不过去。
- 升级方式不变：签名与之前一致，直接覆盖安装，任务和记录都保留。本版没有新增权限，没有新增第三方组件。
