# TuxunDown v2.3.0

2.3.0 让下载引擎在途中「自己会动脑子」：线程数不再是开下就定死，而是边下边调整；空间不够会在开下之前就说清，不再下到一半才爆。这一版还做了一轮完整的安全审计，把密码、备份和浏览器几个地方都收紧了。

## 新功能

- **动态线程伸缩**：以前下载开始时的试探定下多少线程，就一直用到底。现在下载途中每几秒重新评估一次：加一条连接、总速度还在涨，就继续加；速度早就不涨了，就把多余的连接收回来——同样的速度、更少的连接，省电，也少惹服务器限流；速度明显下滑时也会主动减连接试试。调整只发生在连接空闲的间隙，绝不会把下到一半的分片掐断；试探错了会自动回退并记住教训，不会来回抖动。任务卡片上的线程数现在是实时值。三个机制各管一段：试探定起点、伸缩管中途、按站记忆存终局最优（下次下同一个站直接用这次的最终线程数起步）。
- **空间预检**：新建和续传在下第一字节之前先算账：文件有多大、这台手机还剩多少空间、其他正在下载的任务还要写多少。不够就停在卡片上明说「这个文件有 X，可用空间只有 Y，还差 Z」，清出空间点继续即可。文件大小未知（如流媒体）或空间查不到（自选文件夹）时不误拦。
- **设置搜索**：设置页顶部新增搜索框，输入「代理」「限速」「备份」「深色」等关键词即可直达对应分组。
- **统计页站点排行**：新增「下载最多的站点」前五名（按下载量，带文件数），全部是本机统计，不上传。

## 优化

- **嗅探补漏**：有些视频页只把视频直链写在网页的社交分享标记里（og:video、twitter:player:stream 等），页面上没有任何下载链接。嗅探现在会读这些标记，把视频抓出来列为可下载资源。

## 安全审计（第 9 轮）

- **代理密码加密保存**：以前代理密码是明文存在设置文件里的，现在改用系统钥匙圈（Android Keystore）的 AES 加密保存，旧版本存的明文会在首次读取时自动迁移成密文。系统备份文件里本来就不含代理密码，这次连应用内导出备份也更严了（见下）。
- **导出备份剥离令牌头**：导出的任务备份以前只剥 Cookie，现在 Authorization、Proxy-Authorization 这类令牌头一并剥离，不会跟着备份文件到处走（手机里本地续传用的记录不受影响）。
- **系统备份收紧**：安卓系统自带的云备份/换机传输不再带走本应用的设置文件和任务记录（任务记录里有续传用的登录 Cookie）；换机请用应用内的「导出全部备份」，它按设计就不含密码和令牌。
- **内置浏览器关掉本地文件访问**：明确关闭了 WebView 的本地文件与内容访问（之前是系统默认的开），网页只能走 http/https，碰不到手机上的文件。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 安装包体积：以正式发布包实测为准（验收包约 1.25 MB 量级，没有变臃肿）；没有新增任何第三方依赖，加密用的是系统自带能力。
