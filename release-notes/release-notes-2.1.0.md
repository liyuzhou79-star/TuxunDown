# TuxunDown v2.1.0

2.1.0 做了一轮专门的并发审计：把下载引擎的多条线程、服务的队列管理、任务存盘和通知刷新放在一起逐条对线，修掉了一批平时很难撞见、一旦撞见就很烦的竞态问题；同时加上单任务限速、完成自动动作、整段文字提链接、主题图标和桌面小部件。

## 新功能

- **单任务限速**：展开任意任务卡片，可以给这个任务单独设一个速度上限（512KB / 1MB / 3MB / 5MB）。它和全局限速同时生效时取更小的那个，下载中改也立刻生效。
- **下载完成自动动作**（设置 → 提示，默认关）：「下完安装包自动调起安装界面」和「下完文件自动打开」。说明白：自动安装只是把系统安装界面调起来，最后的「安装」按钮仍要你亲手点，App 不会也不能替你确认；要是系统拦住了后台弹出，卡片上会写明，点通知或卡片按钮也一样。
- **整段文字提链接**：把一大段带链接的文字（聊天记录、帖子、更新说明）分享进来，或粘进新建框，会自动把里面的全部 http / ftp 链接提出来：多个就批量建任务，只有一个就当普通链接处理。中文标点不会再被误当成链接的一部分。
- **桌面小部件**：把 TuxunDown 小部件加到桌面，能直接看进行中的任务数和总进度，点一下打开 App。进度数字和通知栏用的是同一套算法，两边不会打架。

## 修复（并发审计轮）

- **同一任务被两个引擎同时下载**：服务在极端时序下可能启动两条队列管理线程，各自的账本互不可见，会把同一个任务领走两遍、往同一个文件里交错写。现在加了全程持有的任务占用登记，第二个引擎根本起不来；队列线程本身的启动也上了锁。
- **重试等待中删任务会被无视**：自动重试的退避等待期间点删除，旧逻辑要等它把整个文件重新下一遍才肯删。现在等待一结束先查删除标记，文件和记录立刻清掉。
- **完成瞬间的操作被吞**：下载完成那一瞬间点的删除会被无视、点的暂停会让一个已经下完的文件迟迟不改名。现在完成判定以引擎的返回结果为准，完成后的删除也会被如实执行（记录删掉，下好的文件保留，和删已完成任务一致）。
- **开始瞬间的暂停被覆盖**：任务刚被领走、引擎还没注册时点暂停，旧逻辑会把暂停覆盖成下载中。现在启动前会再确认一次状态，暂停就是暂停。
- **任务列表的多线程读写**：任务列表现在用写时复制结构，界面、队列、存盘三边同时读写不会再互相踩到半截状态。
- **HLS 播放列表换内容认不出来**：以前续传只比分片数量；播放列表内容变了但数量相同（比如换了一版视频）时会把旧片段和新片段拼成一个坏文件。现在按全部分片地址算指纹，内容一变就重新合并。

## 优化

- **安卓 13 主题图标**：桌面图标加了单色层，开启「主题图标」后会跟随壁纸配色。
- **全面屏安全区**：目标系统升到安卓 15 后，窗口会被强制画到屏幕边缘。这一版逐页核过：主页、设置、新手引导、嗅探浏览器和扫码页的按钮与文字都不会再被状态栏、手势条或刘海挡住（扫码的相机预览保持全屏，只有提示和按钮上移）。

## 说明

- 升级方式不变：正式签名与之前一致，直接覆盖安装即可，不用卸载，任务记录都保留。
- 安装包体积守住 2.0 的瘦身成果，没有因为新功能涨回去。
