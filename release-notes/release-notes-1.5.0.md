# TuxunDown 1.5.0

这一版主题是「速度与稳定」：让 App 记住每个站点的脾气、把速度数字测准，同时把启动和断网这些容易翻车的地方都加了兜底。照例免费、开源、无广告，所有任务都在你的手机本地完成。

## 新功能

- **按站点记住最佳连接数**：同一个站点下过一次，App 会记住它最合适的连接数（保存 30 天），下次直接用，不用每次从头试探，起步更快。连续失败两次会自动忘掉重新学。
- **断网自动等恢复**：下载中途断网，任务不再直接判失败，而是停泊等网络回来，恢复后自动接着下；每轮最多自动恢复 3 次，不会无限耗着。

## 优化与修复

- **速度数字更准**：速度采样改成严格的 1 秒节拍（原先会慢慢漂移），卡片上的大号速度、主页汇总、通知栏和速度曲线读的是同一个数，不再各说各话；「90 秒曲线」现在真的是 90 秒。
- **连接缓冲自适应**：每条连接的读写缓冲按连接数自动调整，总量封顶，连接开得多也不会白占内存。
- **启动安全审计**：逐条复查了所有开机第一帧会走到的路径——旧版本存下的设置值类型不对时，原先可能直接闪退，现在全部有兜底默认值；系统 WebView 损坏时嗅探页会给出人话提示而不是崩掉。
- **后台保活卡**：设置里新增「后台运行」卡片，显示电池白名单状态并可一键跳去设置，还写清了 Flyme 系统里手动放行的具体路径和「最近任务锁定」的做法，后台下载更不容易被系统杀掉。

## 说明

- 本版可直接覆盖安装在 1.2.0 及后续版本之上，不用卸载。
- 按站点记连接数只记「连接数」这个数字本身，不记录你的下载内容，数据只存在本机。
